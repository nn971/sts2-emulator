The census and matrix have different units. Census rows are source expressions; migration rows are semantic sampling sites. One site can have many call expressions, and one generic provider expression can serve many semantic sites. Neither count should be used as the other's completion denominator. The census also scans Core for direct typed or target-typed System.Random construction, shared-instance use, and RandomNumberGenerator calls, so ad hoc entropy sources can be surfaced alongside provider-backed RNG expressions. It lists explicit typed random-request constructions with their positional or named `SiteId` resolution against the registry and matrix; dynamic or aliased request arguments remain review items. It does not detect indirect or aliased entropy sources.

Stone of All Time's pre-entry potion-slot query covers Native and retained legacy routes. Native uses the exact bounded-index transform; the legacy route uses an equal-support ReferenceNature model marked `UNVERIFIED`, with its request ordinal following the Event-selection ticket.

1. owner, operation kind, occurrence identity and ordered legal support;
2. active provider and private state/constraint fingerprint;
3. player-visible, Nature-visible and privileged-inspector projections;
4. resolver and ordinary mechanics continuation, including hook-once behavior;
5. probability status and provenance, distinct from native cursor/parity status;
6. exact unsupported/fail-closed handling and evidence link.
