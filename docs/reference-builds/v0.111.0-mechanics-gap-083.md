# v0.111.0 mechanics gap 083 — Golden Compass

Golden Compass is an Act 2 Tezcatara reward. On acquisition, it stores the
zero-based act index and replaces that act's map with its 17-floor single path,
ending at the boss. The replacement retains the current floor and node when
obtained mid-act; its map effect is active only in the acquisition act.

Executable coverage follows the Tezcatara reward into the acquisition hook,
checks every room and edge in the generated map, validates the persisted act
index and active-act gating, and checks the mid-act current-node handoff.
Native Ancient assignment, RNG parity and live room replay remain unverified.
