# v0.111.0 mechanics gap 113 — Belt Buckle

Belt Buckle is a Shop shared relic. It grants 2 Dexterity at combat start
when the owner has no potions, and after the owner uses their last potion.
The relic is inactive while a potion remains.

The executable fixture covers empty and nonempty potion slots at combat
start, using one potion while another remains, using the last potion, and a
melted copy. The current emulator has no mid-combat potion procurement or
discard action, so those two native callbacks are outside this fixture.
