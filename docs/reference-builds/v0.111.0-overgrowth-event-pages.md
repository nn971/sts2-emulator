# Native-shaped Act 1 Overgrowth event pages (v0.111.0)

Reference pin: `Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`,
especially `src/Core/Models/Events/TabletOfTruth.cs`,
`DenseVegetation.cs`, `Wellspring.cs`, `WhisperingHollow.cs`,
and `src/Core/Models/Encounters/DenseVegetationEventEncounter.cs`.

This is **single-player Silent-only** emulator development.
Cross-character and multiplayer-only reward mechanics remain postponed.
The prototype models legal actions and persistent canonical state;
the RNG streams and full event rules are not yet proven seed-parity exact.

## Tablet of Truth

Previously only the first Decipher effect was implemented. The native
event has a five-stage sequence:

| Decipher | Max HP cost | Deck upgrade | Next options |
|---|---|---|---|
| 1 | 3 | one eligible random card | Decipher again or Give Up |
| 2 | 6 | one eligible random card | Decipher again or Give Up |
| 3 | 12 | one eligible random card | Decipher again or Give Up |
| 4 | 24 | one eligible random card | Decipher again or Give Up |
| 5 | current max HP minus 1 | all eligible deck cards | event ends |

Smash at the initial page heals 20 HP and ends the event. Intermediate
Decipher progress is persisted as `EventState.NativePageIndex`, with
explicit legal actions on pages 1–4. Maximum HP reductions clamp
current HP; lethal costs end the run. The first four random upgrades
use the prototype event RNG. Upgradability is still approximated by
an explicit rarity/unplayable filter and current upgrade level.

A completed page is not a completed map room: the one event room is
recorded only when Smash, Give Up, or the fifth Decipher finishes.

## Wellspring and Whispering Hollow

**Wellspring/Bathe** now removes the selected persistent deck card
before adding Guilty. The pending curse ID lives in
`EventState.DeferredCardId`; adding it through `AppendCard` only
after the removal preserves card-added hooks and gives Guilty a new
persistent instance ID. The Bottle option still uses prototype potion
creation and replacement semantics.

**Whispering Hollow/Hug** transforms the chosen persistent card
before dealing its unblockable 9 HP of damage, using the existing
deferred HP-effect callback. The random transform still uses the
prototype pool; event-specific native RNG parity is separate.

**Whispering Hollow/Gold** now draws a 26–44 gold price when
the event first appears, stores it in `EventState.NativeEventGold`,
and charges the saved value when the player accepts the two
potion rewards. The potion identities and call ordering still use
prototype RNG, but the paid gold is no longer fixed at 35.

## Dense Vegetation

The initial options are now:
- **Trudge On:** suffer 8 HP damage and gain a per-event 61–99 gold
  roll. The roll is stored in `EventState.NativeEventGold` when the
  event is generated, rather than hard-coding 80 gold. A lethal
  trudge ends the run.
- **Rest:** heal as at a rest site (30% of max HP, with
  `RestSiteHealed` hooks), then reveal the one mandatory Fight
  follow-up action.
- **Fight:** enter the scripted
  `proto.native.encounter.dense_vegetation_event`, exactly four
  Wrigglers, through the normal combat engine. The encounter
  has zero normal map-pool selection weight and does not advance
  the Act 1 ordinary-combat pool. The current map room stays an
  Event for the entire fight.

When this combat is won, combat-win callbacks still run, but the
event completes directly **without a combat reward screen**, gold,
potions, cards, or relics. No extra map floor or completed room
is introduced. This follows the native
`EnterCombatWithoutExitingEvent(..., Array.Empty<Reward>())` path.

## Remaining event work

Other Overgrowth event pages and effect types are still partially
implemented, including scripted enchants, target-specific transforms,
native event RNG/dynamic costs, and future region-specific encounters.
The event state machine deliberately does not introduce a generic
cross-character reward model. Fidelity comparison remains the
subsequent milestone after native-shaped Act 1 generation.
