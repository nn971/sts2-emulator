# v0.111.0 mechanics gap 072 — Fiddle

Fiddle is offered in Vakuu's first relic pool in Glory. It adds two cards to
each hand draw. During its owner's turn, it also prevents non-hand draws;
non-hand draws remain allowed when the player's side is inactive.

The shared hand-draw bonus already included Fiddle, while the turn draw path
added a second hard-coded +2. That duplicate was removed. Executable coverage
checks the Vakuu relic pool, a seven-card opening and turn-two hand draw, a
blocked player-turn non-hand draw, and an allowed off-turn draw. Normal Ancient
assignment and native RNG parity remain unverified.
