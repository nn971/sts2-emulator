# v0.111.0 mechanics gap — pass 030

This pass promotes **Nibbit** as a source-backed Act 1 monster model and adds exact reference
formations for both of its native Overgrowth encounters.

## Nibbit model

Pinned v0.111.0 values:

- HP 42–46 at A0–A7;
- HP 44–48 at A8+;
- Butt: 12 damage, 13 at A9+;
- Hesitant Slice: 6 damage plus 5 Block;
- at A8+ Slice gains 6 Block;
- at A9+ Slice deals 7 damage;
- Hiss: gain 2 Strength, 3 at A9+.

The move loop itself is fixed:

`Butt -> Slice -> Hiss -> Butt -> ...`

Only the initial state depends on formation.

## Formation-sensitive opener

The existing typed conditional enemy-AI state is sufficient for the native opener rules:

1. if the Nibbit is alone, begin at Butt;
2. otherwise if it is behind the front living formation position, begin at Hiss;
3. otherwise begin at Slice.

After the first move, all cases enter the same fixed three-move cycle.

This keeps encounter-specific formation state in the encounter constructor while the enemy model
contains only the source-backed conditional rule.

## Reference encounters

Two weight-0 reference encounters are now present.

### `NIBBITS_WEAK`

One Nibbit at formation position 0.

This makes the conditional opener resolve to Butt.

### `NIBBITS_NORMAL`

Two Nibbits at positions 0 and 1.

The position-0 Nibbit opens with Slice; the rear Nibbit opens with Hiss.

The definitions remain weight 0 because native weak/normal pool selection is a separate fidelity
claim from encounter formation.

## Regressions

Focused tests verify:

- A0/A8 HP ranges;
- A8 Slice Block;
- A9 Butt/Slice damage and Hiss Strength;
- lone Butt -> Slice -> Hiss cycling;
- paired front-Slice / rear-Hiss openers;
- Strength affecting later attacks;
- exact one-Nibbit and two-Nibbit reference formations.
