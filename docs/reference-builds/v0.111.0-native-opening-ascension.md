## Implemented opening rules

Only the opt-in `PrototypeNativeOvergrowthRunFactory` is changed.
Ordinary `prototype-silent-v0` JSONL `reset` preserves its historical
six-floor, 70 HP, two-slot prototype opening.

- **Neow / Weary Traveler (A2+):** native `AncientEventModel`
  sets the player's current HP to zero on first visiting Neow,
  then heals only 80% of the missing HP. At Silent's native
  70 maximum HP, the result is **56/70 HP** at A2+ and
  **70/70 HP** at A0–A1. The native-structure factory now
  initializes the Neow decision state with those values.
- **Tight Belt (A4+):** native players start with three potion slots;
  `AscensionManager.ApplyEffectsTo` removes one at A4+.
  The native-structure profile now has **three slots at A0–A3**
  and **two slots at A4–A10**. Potion-slot capacity is tracked
  by persistent world provenance, so a hybrid Act 2/3 retains the
  original belt size. Phial Holster and other capacity-changing
  relics continue to contribute their own slots.
- **Ascender's Bane (A5+):** the native curse is
  Eternal, Unplayable, and Ethereal and is added at A5+.
  The implementation already had this correctly defined card
  but did not insert it during native-run creation.
  The A5+ factory now puts this card into the opening deck.

## Oracle evidence and fidelity boundary

The natural Silent A10 Overgrowth capture (pinned
`v0.111.0 / 41cef1ea`, session captured October 8, 2026)
records the first encounter at **56/70 HP** and an opening
13-card combat draw pile consisting of five Strikes, five
Defends, Neutralize, Survivor, and Ascender's Bane.
That is consistent with the relevant pinned native sources.

**Known A0 uncertainty:** the direct native `Silent.StartingDeck`
definition contains *twelve* cards and native A5 adds Bane.
An earlier A0 probe was reported as a thirteen-card starting
combat deck containing the colorless Restlessness, but this
extra card's provenance has not been established from the
native starting-deck source. To avoid silently breaking the
recently agreed AI training-gate contract, the emulator still
uses the previous Restlessness thirteenth card at A0–A4;
at A5+ it uses Bane in that additional slot. This is a
deliberate **interim compatibility decision**, not a native
source-backed rule that Restlessness is given for free.
Further A0 Neow/card-provenance evidence is needed before
retiring the compatibility behavior and updating the
`sts2-ai` training gate in lockstep.

This pass does **not** reconstruct native seed RNG parity,
Ascension map generation RNG, noncombat event histories, or
complete native Neow UI lifecycle. It does not import the
user-owned raw 85 MB probe into the repository.

A3, A4, A5 and A10 starting HP, potion capacity, card IDs,
fork isolation, and legacy run isolation. The JSONL

and A10 public opening observations across the declared
native-reset interface.
