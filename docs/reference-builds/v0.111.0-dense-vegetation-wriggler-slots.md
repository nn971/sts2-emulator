# Issue #6 — Dense Vegetation Wriggler AI slots

**Reported failure:** `Enemy 'proto.enemy.wriggler' AI conditional state 'init' has no matching branch` when a native Overgrowth self-play run takes Dense Vegetation's `rest` then `fight` choice and ends its first player turn.

**Root cause:** `proto.native.encounter.dense_vegetation_event` was defined using only four enemy IDs. The generic encounter resolver assigned positions 0–3 but no `SlotName`. Wriggler's `init` conditional state relies on slot-name equality, so no branch matched when the enemy acted. The previous event test eliminated all Wrigglers before their first action and missed the failure.

## Pinned source at v0.111.0

Source: `Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`.

- `src/Core/Models/Encounters/DenseVegetationEventEncounter.cs` creates four **non-stunned** Wrigglers with `Slots = ["wriggler1", "wriggler2", "wriggler3", "wriggler4"]`.
- `src/Core/Models/Monsters/Wriggler.cs`: `INIT_MOVE` selects **NASTY_BITE** for `wriggler1` and `wriggler3`, and **WRIGGLE** for `wriggler2` and `wriggler4`; moves alternate thereafter.
- `src/Core/Models/Encounters/PhrogParasiteElite.cs` uses the same numbered Wriggler slots.
- `src/Core/Models/Powers/InfestedPower.cs` summons four Wrigglers using those slots, with `StartStunned = true`; after the temporary stun the numbered slots decide each Wriggler's opening move.

## Emulator fix

1. Dense Vegetation's event-only encounter now specifies an explicit four-enemy `Formation` with source-matching numbered `SlotName` fields.
2. The Wriggler state machine's conditional branches use source-matching `wriggler1`–`wriggler4` values, instead of the previous synthetic `bite`/`wriggle` strings. Missing slot names continue to fail fast; no silent default was added.
3. The Phrog Parasite death summons use the same native numbered names, preserving its previous alternating bite/wriggle behavior and initial stun.
4. The Dense Vegetation regression tests `rest → fight → end_turn → end_turn` with **all four Wrigglers alive** at both A0 and A10. It checks initial slot assignment, no initial stun, player HP, infection generation, two successive move sequences, and state invariants. Existing rewardless-combat and Phrog summon tests remain.

This addresses the event-combat crash without modifying AI training, suppressing the encounter, or weakening the Wriggler conditional-state invariant. The battle simulator still uses its prototype RNG and is **not** a full native seed/action replay.
