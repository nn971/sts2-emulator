# v0.111.0 mechanics gap 105 — Sturdy Clamp

Sturdy Clamp is a Rare shared relic. When the owner’s Block would clear, it
keeps up to 10 Block. The relic does not preserve another creature’s Block;
melted copies do not trigger.

The player block-reset stage now applies this retention before later turn-start
Block grants. Executable coverage checks Block above and below the cap and a
melted copy.
