## Scope and source-based parameters

This milestone registers explicit **native-structure map profiles** for
Hive and Glory, with the same basic seven-column / seven-path geometry and
non-crossing constraints as StandardActMap, without changing Overgrowth's
existing generator or the historical six-floor prototype route.

| Parameter | Hive (act 2) | Glory (act 3) |
| --- | ---: | ---: |
| `BaseNumberOfRooms` | 14 | 13 |
| Last ordinary map floor | 14 | 13 |
| Boss floor | 15 | 14 |
| Fixed first-floor room | Combat | Combat |
| Fixed treasure floor (`boss-7`) | 8 | 7 |
| Fixed preboss rest floor | 14 | 13 |
| Generated rest quota | Gaussian(6,1) truncated [6,7] | `NextInt(5,7)`: 5–6 |
| Generated unknown quota | Gaussian(12,1) truncated [10,14] minus 1 | Same, minus 1 |
| Shop quota | 3 | 3 |
| Elite quota | 5 (or 8 at Swarming Elites) | Same |

The typed maps preserve distinct entry nodes, act-prefixed node coordinates,
forward-only edges, one terminal boss and reachable rows. Their validator is
separate from both the full-scale Overgrowth profile and the previous small
War Historian Repy fixture. Map generation is reproducible and fork-safe.

`PrototypeNativeLaterActFixture.Create(seed, act, ascension, lanternKeys)`
instantiates an isolated map state using the native **act-local map RNG**
constructor `Rng(runSeed, "act_2_map")` or `act_3_map`, rather than
the six legacy streams. `PrototypeNativeLaterActMap.GenerateNativeWithAudit`
exposes the final xoshiro256** snapshot and counter to replay RNG consumption.
The earlier `Generate(RngBundle, ...)` entry point still uses only the legacy
`map` stream, preserving the historical adapter and its RNG behavior.

This is **not** an end-to-end run; its regional encounter, event and loot bags
remain incomplete. Entry to ordinary Hive/Glory rooms throws
`NotSupportedException` before mutating state, rather than silently
selecting six-floor prototype content. Carrying a Lantern Key into a Glory
Event or Unknown node continues to force War Historian Repy.

## Outstanding fidelity blockers

- The opted-in map RNG now uses the native act-local seed, native bounded
  sampling, Gaussian and Fisher-Yates operations. **The map-building algorithm
  still has provisional path ordering, crossing/pruning, shuffle and room
  placement.** Its precise native call order, final RNG counters and resulting
  maps are not yet byte-for-byte verified against pinned `StandardActMap`.
  This is an RNG ownership migration, not a native map parity claim.
  The legacy generator remains explicitly prototype-only.
- The later-act actual encounter bags, full regional event pools,
  Ancient selection, rewards, transitions and live parity probes remain
  unimplemented; do not opt into normal room execution.
- The prior `RepyFixtureMapProfileId` still supports isolated two-node
  tests independently of this larger map source.
