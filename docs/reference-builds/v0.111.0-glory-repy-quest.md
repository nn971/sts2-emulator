# v0.111.0 Glory: Lantern Key -> War Historian Repy

Target: v0.111.0 / 41cef1ea, audited source
`Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`.

Sources:
- `src/Core/Models/Cards/LanternKey.cs`
- `src/Core/Models/Events/WarHistorianRepy.cs`
- `src/Core/Models/Relics/HistoryCourse.cs`

## Implemented, forced quest route

- In Glory (native act index 2 / emulator act 3), a persistent
  Lantern Key overrides an unknown map node to an Event room and
  replaces an eligible event with War Historian Repy. Both direct Event
  and Unknown rooms are intercepted. Other unsupported Glory unknown
  rooms still reject rather than using prototype fallbacks.
- Repy's initial options unlock the cage or chest. Initial choice
  removes one **specific** Lantern Key card from the persistent deck.
- Cage sets `FreedRepy` on the run and obtains the event-only
  `History Course` relic.
- Chest pre-rolls two potion offers and two *distinct* relic offers
  at the moment it is chosen. Both offers are individually optional
  and all hidden selections are persisted in the event state.
- If more keys remain after the initial choice, the **opposite**
  choice becomes available, after reward resolution. That second
  choice removes *all* remaining Lantern Keys, matching the
  source's single-player RemoveLanternKeysForSecondChoice.
- Snapshot forks, unknown-room RNG non-consumption, multiple-key
  consumption, independent optional rewards and page legality are
  covered by deterministic regressions.

## Known differences and blockers

- Native chest opens a single four-reward screen (2 potion rewards,
  2 relic rewards). The emulator presents two independent stages,
  each with one potion and one relic; skipping the first stage
  still reveals the second. All four outcomes are rolled on entry,
  independently of prior reward-taking actions.
- The v111 native CardFactory/RelicPool bags and RNG stream ownership
  are not integrated. These forced fixtures currently draw from the
  implemented prototype potion and relic pools. This changes reward
  distributions, not the number or categories of offers.
- `History Course` now implements the native
  `AfterAutoPrePlayPhaseEntered` hook: capture the last finished
  non-dupe Attack on each player turn, then on turn 2+ duplicate
  and auto-play it after start-turn effects. The copy uses the
  existing source-shaped free auto-play and `combat_targets` RNG,
  retains upgrade/card state, dispatches normal card-play triggers,
  and is excluded from the next turn's source history.
- Combat-history snapshots and duplicate markers are cloned on forks.
  Capturing at `CardPlayed` approximates the native
  `CardPlaysFinished` reference in the absence of an independently
  modeled native history list. Multi-character owner filtering and
  native live-trace parity are unverified. History Course remains
  conservatively classified **partial** pending native validation.
- Glory map generation, complete event bags, later acts and
  native oracle replay are still gated. This patch is an explicit
  single-event quest slice and supplies no native parity claim.
