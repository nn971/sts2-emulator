# v0.111.0 mechanics gap 076 — Biiig Hug

Biiig Hug is a Tezcatara Ancient reward in Hive. It removes four chosen deck
cards and generates a Soot at a random position after the discard pile is
recycled into the draw pile.

Executable coverage checks the Act 2 reward choice and four-card removal
schema, then recycles a discard pile and verifies a temporary Soot enters the
combat piles. A melted copy does not generate Soot. Native Ancient assignment
and shuffle RNG parity remain unverified.
