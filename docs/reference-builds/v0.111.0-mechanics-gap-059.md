# v0.111.0 mechanics gap 059 — Pocketwatch

Pinned `Pocketwatch.cs` is a Rare shared relic. During combat it counts cards
played by its owner. Starting on turn two, when the previous player turn had
three or fewer card plays, it adds three cards to that turn's opening hand.
The count rolls over at each new player turn and combat counters reset with the
combat state.

The emulator now records card plays from the prior turn in combat counters and
applies Pocketwatch's conditional bonus during opening hand draw. Multiple
active copies each supply their bonus. Pocketwatch is included in the ordinary
Rare relic pool; coverage checks both that acquisition path and the three-play,
three-card source values. This effect uses no additional random draw.
