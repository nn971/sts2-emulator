# v0.111.0 mechanics gap 110 — Gnarled Hammer

Gnarled Hammer is a Shop shared relic. On acquisition it offers up to three
eligible Attack cards in the deck for Sharp +3 enchantments. The choice can
finish with fewer than three cards selected; non-Attacks and cards already
enchanted are ineligible.

The executable fixture checks the three-card cap, optional completion,
Attack-only eligibility, and the saved enchantment amount.
