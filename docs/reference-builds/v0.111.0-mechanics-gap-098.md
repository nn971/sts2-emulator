# v0.111.0 mechanics gap 098 — Gorget

Gorget is a Common shared relic. At combat start, it grants the owner 4
Plating. The existing Plating power grants its current stacks as Block at
turn end and loses one stack at later turn starts. Melted copies do not
trigger.

Executable coverage dispatches the combat-start and turn-end callbacks,
checks the four Plating stacks and the resulting four Block, and verifies a
melted copy does not trigger. It also checks registration in the shared pool
and Common rarity.
