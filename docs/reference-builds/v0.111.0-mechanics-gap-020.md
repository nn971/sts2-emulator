# v0.111.0 mechanics gap — pass 020

This pass promotes Knight Gang from a set of isolated mechanics to the first complete source-backed
A0 native encounter in the prototype.

## Encounter content

`proto.encounter.knight_gang` is now a positive-weight Act 3 Elite encounter containing, in order:

1. Flail Knight;
2. Spectral Knight;
3. Magi Knight.

It therefore participates in the normal weighted Act 3 elite selection path.

## Combined mechanics exercised

The encounter composes previously independent kernel features:

- Flail Knight's constrained random policy;
- enemy Strength and per-hit damage modification;
- Spectral Knight's source-owned Hex;
- Hexed -> Ethereal card behavior;
- Magi Knight's Dampen;
- reversible Upgrade suppression;
- source-bound cleanup;
- enemy Block reset/timing;
- Magi's fixed Ram/Prep/Magic Bomb loop.

No encounter-specific combat branch was added.

## Five-turn A0 regression

A combined encounter test uses a fixed RNG seed and an upgraded Silent card.

The first five turns verify:

### Turn 1

- Flail uses Ram for 15;
- Spectral applies Hex;
- Magi uses Power Shield for 6 and gains 5 Block.

Total incoming damage: 21.

The upgraded card becomes source-owned Hexed.

### Turn 2

- the seeded Flail choice is Flail for 9 × 2;
- Spectral uses Soul Slash for 15;
- Magi applies Dampen.

The card is now both Hex-governed and Dampen-suppressed: its effective Upgrade is zero while its
persistent level is stored.

### Turn 3

- Flail repeats Flail for 9 × 2, which is still within its two-use limit;
- Spectral uses Soul Flame for 3 × 3;
- Magi uses Ram for 10.

### Turn 4

- Flail uses War Chant and gains 3 Strength;
- Spectral uses Soul Slash for 15;
- Magi uses Prep and ends with 5 Block.

### Turn 5

- Flail's Strength-boosted Ram deals 18;
- Spectral uses Soul Flame for 3 × 3;
- Magi uses Magic Bomb for 35.

The regression pins the combined post-turn HP as well as each enemy's move identity and source
state.

## Milestone reached

This is the first encounter in the prototype whose important A0 mechanics come directly from the
native/source-backed model rather than from placeholder enemies.

That makes it a useful first differential-testing target against the native oracle.

## Remaining fidelity

Knight Gang is currently an **A0** fidelity milestone.

The next structural work should add typed Ascension support so the encounter can represent:

- A8+ HP: Flail 108, Spectral 97, Magi 89;
- A8+ Magi shield values;
- A9+ attack values for all three knights.

After that, the most valuable step is an oracle capture/diff of real Knight Gang turn sequences and
RNG decisions rather than immediately broadening to another encounter.
