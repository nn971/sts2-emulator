Empty Cage is an Ancient relic. `AfterObtained` opens a deck removal selection
for two cards, then removes each selected card from the deck. The source
selection filters out unremovable cards. The emulator includes it in the boss
relic pool and uses its generic relic acquisition choice: select up to two
eligible cards and remove them. If fewer than two cards can be removed, the
selection count is limited to the available candidates.

Native selection UI and RNG are not modeled; the chosen card IDs are explicit
run actions.
