# v0.111.0 mechanics gap 063 — Lizard Tail

Pinned `LizardTail.cs` is a Rare shared relic. Its late death-prevention hook
can be used once; after preventing death, it marks `WasUsed` and heals 50% of
Max HP, with a minimum of 1. The emulator registers it in the Rare pool and
persists `WasUsed` on the relic instance. Run HP-loss effects use the shared
prevention path, while combat death resolution checks automatic potions before
Lizard Tail.

Coverage checks Rare-pool registration, one-use healing, persisted use, and a
second fatal HP loss remaining lethal.
