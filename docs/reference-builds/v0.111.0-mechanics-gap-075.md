# v0.111.0 mechanics gap 075 — Diamond Diadem

player-side turn, it grants 20 Block and one Blur.

turn-start event. It verifies the Block and Blur, turn-one gating, and that a
melted copy has no effect. Normal Ancient assignment and native RNG parity
