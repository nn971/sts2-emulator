# v0.111.0 mechanics gap 089 — Bellows

Bellows is a shared Rare relic integrated into the supported relic pool. At
the start of the owner's first turn in each combat, it upgrades every
upgradeable card currently in hand. Cards drawn after that trigger wait until
the next combat. It has no effect on later turns or while melted.

Executable coverage dispatches the first-turn trigger and checks that a
handed Strike upgrades while a card already at its upgrade cap, a Wound, and a
card in the draw pile do not change. It also checks the later-turn and melted
cases. The shared hand-upgrade effect now respects each card's maximum upgrade
level, which also applies to Blessing of the Forge.
