# Hive Amalgamator event audit

Target: single-player STS2 v0.111.0 / source commit
`706ef1c9fa2219220065849fd5265328607ece20`.

The pinned [`Amalgamator.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Events/Amalgamator.cs)
has source SHA-256
`d0f41ef96e918a6c65a11293ff1f35a187ed09ae70d95419c17030b05f720727`.
It allows the event only when every player owns at least two removable Basic
Strikes and two removable Basic Defends. The single-player emulator uses the
same four eligibility conditions.

The complete source branch inventory has seven paths:

| Source path | Behavior | Verification |
| --- | --- | --- |
| `page/INITIAL` | Show the two combination choices after eligibility succeeds. | `SourceEligibilityRequiresBothBasicTaggedPairs` checks both option IDs and removes the event when either pair is incomplete. |
| `initial/COMBINE_STRIKES` | Select exactly two removable Basic Strikes. | `RemovesOnlyTwoMatchingBasicCardsBeforeCreatingUltimate(combine_strikes, ...)` checks every offered instance. |
| `page/INITIAL/COMBINE_STRIKES` | Resolve the initial Strike choice into its deck-selection continuation. | Same Strike test checks two selections are required and the event stays open while selecting. |
| `page/COMBINE_STRIKES` | Remove the selected cards, add one Ultimate Strike instance, then show the completion page. | Same Strike test checks exact deck contents, instance ID, snapshot restore, fork, and the completion-page action. |
| `initial/COMBINE_DEFENDS` | Select exactly two removable Basic Defends. | `RemovesOnlyTwoMatchingBasicCardsBeforeCreatingUltimate(combine_defends, ...)` checks every offered instance. |
| `page/INITIAL/COMBINE_DEFENDS` | Resolve the initial Defend choice into its deck-selection continuation. | Same Defend test checks two selections are required and the event stays open while selecting. |
| `page/COMBINE_DEFENDS` | Remove the selected cards, add one Ultimate Defend instance, then show the completion page. | Same Defend test checks exact deck contents, instance ID, snapshot restore, fork, and the completion-page action. |

The emulator preserves the source's `SetEventFinished` boundary after all
selection effects settle. The final page is a persisted Event state with one
`continue_event` action; it does not consume RNG. Invalid continuation actions
are rejected. The behavior is implemented in
`PrototypeNativeHiveEvents`, `PrototypeRooms`, and
`PrototypeEventContinuations`, with state constraints in
`PrototypeStateInvariants`.

This closes the source branch inventory for Amalgamator only. It does not
establish native RNG or live-game parity for the wider Hive event pool.
