# v0.111.0 mechanics gap 069 — Forgotten Soul

`ForgottenSoul.cs` is an Event-rarity Glory relic awarded by **Accept** in
Grave of the Forgotten. Each `CardExhausted` event deals 1 unpowered damage to
one random living enemy. The existing generic relic trigger resolver handles
the effect; Forgotten Soul remains outside the ordinary relic reward pool.

Executable coverage checks the Act 3 event reward and event-only pool
membership, then dispatches `CardExhausted` against two living enemies. It
verifies one total HP loss and no effect from a melted copy.
