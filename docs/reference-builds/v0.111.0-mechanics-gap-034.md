# v0.111.0 mechanics gap — pass 034

This pass reconciles already-implemented Overgrowth normal enemies, promotes three additional
source-backed normal formations, and makes the complete Overgrowth normal encounter inventory
explicit.

that the completeness ledger still marked "not started":

- Axe Raider;

- Crossbow Raider;
- Tracker Raider;
- Cubex Construct.

accounted for.

## Singleton normal formations

Two native normal encounters are unambiguous singleton constructors and are now represented as
weight-0 reference encounters:

- `MAWLER_NORMAL` -> one Mawler at formation position 0;
- `CUBEX_CONSTRUCT_NORMAL` -> one Cubex Construct at formation position 0.

Focused tests verify both concrete formations.

## Ruby Raiders

The native Overgrowth Ruby Raider encounter contains three raiders chosen from the five available
types without replacement:

- Assassin Raider;
- Axe Raider;
- Brute Raider;
- Crossbow Raider;
- Tracker Raider.

This maps directly to the existing generic `ChooseDistinct` encounter formation policy with
`EnemyCount = 3`.

The resulting reference encounter:

- always contains exactly three enemies;
- never contains a duplicate raider type;
- assigns them to formation positions 0, 1, and 2;
- can reach every raider type across deterministic seeds.

No additional Ruby-specific selection primitive was necessary.

Exact native RNG call order remains outside the parity claim.
