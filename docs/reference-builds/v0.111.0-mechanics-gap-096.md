# v0.111.0 mechanics gap 096 — Ringing Triangle

Ringing Triangle is a shared Shop relic integrated into the supported relic
pool. It preserves the owner's hand at the end of the first turn. The normal
discard resumes on later turns, and melted copies do not preserve the hand.

Executable coverage runs the actual hand-discard pipeline for the first turn,
a later turn, and a melted copy. It checks that both ordinary hand cards
survive only the first active turn. Native combat callback timing remains
unverified against a live reference build.
