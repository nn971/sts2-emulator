# Hive Ancient: Orobas dependency audit

Target: single-player STS2 v0.111.0 / source commit
`706ef1c9fa2219220065849fd5265328607ece20`.

This is a source audit for the currently missing Hive Ancient. It does not
claim that Orobas is executable or assigned in normal runs. The exact event
source is [`Orobas.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Events/Orobas.cs)
(SHA-256 `570fb013195b4369939db8728dae9516e46505cd552b5440e8c9386f82920ebb`).

## Opening offers

`GenerateInitialOptions` creates exactly three relic options in order:

1. From a three-entry list consisting of Electric Shrymp, Glass Eye, and one
   additional option. The additional option is Prismatic Gem with probability
   `0.3333333`; otherwise it is Sea Glass configured for one randomly selected
   unlocked character other than the owner. If there is no other unlocked
   character, Sea Glass falls back to the current character. One option is then
   selected uniformly from this three-entry list.
2. One uniformly selected relic from Alchemical Coffer, Driftwood, Radiant
   Pearl, or Sand Castle.
3. One uniformly selected relic from the currently eligible subset of Touch of
   Orobas and Archaic Tooth. Touch requires a starter relic; Archaic Tooth
   requires a transformable starter card. If neither is eligible, the source
   exposes a locked placeholder option.

The source call order is character selection, the Prismatic Gem float roll,
selection from the first three-entry list, selection from Pool 2, then selection
from Pool 3. Empty or singleton candidate behavior and each primitive's stream
consumption must remain explicit when this generation is migrated to native RNG.
The event uses its owned event RNG; the source code alone does not establish
the correct earlier run-start Ancient assignment draw sequence.

## Required effects and dependencies

| Relic | Source-backed effect | Implementation dependencies |
| --- | --- | --- |
| Electric Shrymp | On acquisition, choose one Skill and apply Imbued. | Implemented for the supported Silent Skill catalogue; Imbued auto-plays through the opening-turn pipeline. Native acquisition timing and full Skill-pool validation remain open. |
| Glass Eye | Offer five independent custom card rewards: three Common, three Common, three Uncommon, three Uncommon, and three Rare Silent cards. | Implemented for the supported Silent card catalogue. Acquisition suspends and returns to the interrupted reward; groups persist independently and Driftwood can reroll each once. Native pool/RNG parity remains open. |
| Prismatic Gem | Add one maximum energy and include unlocked character pools in non-Colorless card rewards. | Persistent energy modifier and foreign-pool card catalogue/generation. |
| Sea Glass | Choose fifteen generated cards from one configured character pool: five Common, five Uncommon, five Rare. | Per-character pool catalogue, ordered reward selection, persistent card acquisition. |
| Alchemical Coffer | Add four potion slots and offer four generated potions in those slots. | Four slots and four distinct potions are generated into the new slots; complete potion-pool, replacement/offer continuation and native RNG parity remain open. |
| Driftwood | Reroll each card reward once. | Implemented for generated encounter, Dream Catcher, deferred Neow and Glory Trial card groups. Group-level use is persisted; native card-reward RNG parity remains open. |
| Radiant Pearl | Add one Luminesce to the opening hand of each combat. | Implemented combat-start creation and Luminesce effects; native validation remains open. |
| Sand Castle | Upgrade up to six randomly ordered upgradable deck cards. | Implemented acquisition hook; source stream ownership/native shuffle parity remain open. |
| Touch of Orobas | Replace the starter relic with its ancient upgrade. Silent's Ring of the Snake becomes Ring of the Drake. | Implemented Silent starter eligibility/replacement; native validation remains open. |
| Archaic Tooth | Transform the first eligible starter card into its ancient card. Silent's Neutralize becomes Suppress. | Implemented Silent acquisition transform; other character mappings and native validation remain open. |

Every relic source is pinned in `data/coverage/v111-inventory.json`. In
particular, Sea Glass and Prismatic Gem cannot be implemented faithfully using
the current Silent-only reward catalogue. Offering placeholder relic effects
would make the Ancient reachable while leaving its selection branches
incomplete, so the Ancient must stay unassigned until each offered dependency
is executable.

## Integration sequence

1. Implement the shared acquisition continuations listed above, preserving
   event/reward parent state, independent relic instances, and snapshot/fork
   behavior.
2. Add Orobas's persisted three-option opening and its special relic-instance
   data (Sea Glass character, Touch starter/upgraded relic, Archaic Tooth card
   transform).
3. Add branch tests for each selectable relic, locked Pool 3, empty eligible
   card/potion/relic cases, event-context draw order, and snapshot restore.
4. Integrate Orobas into Hive Ancient dispatch only after all three visible
   options can resolve to completion.
5. Audit run-start Ancient assignment and `run.up_front` draw order separately;
   this event audit does not authorize or imply a normal assignment policy.

Current status: seven of the ten offered relic effects are implemented for the
configured Silent: Electric Shrymp/Imbued, Radiant Pearl/Luminesce, Sand Castle,
Touch of Orobas/Ring of the Drake, Archaic Tooth/Suppress, and Driftwood.
Glass Eye also offers five independently selected or skipped groups of three
cards at the pinned Common, Common, Uncommon, Uncommon and Rare rarities, and
returns to its parent reward after resolution. Alchemical Coffer has a partial
slot/potion acquisition effect. Prismatic Gem and Sea Glass remain
unimplemented; the Ancient event and assignment remain gated, and native
validation is unverified.
Ring of the Drake follows pinned
[`RingOfTheDrake.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Relics/RingOfTheDrake.cs)
(SHA-256 `41ee243f146f5cff3f1bffaca11425359248e1f5ea88b0ee7034f267f0a6c507`):
it adds two hand draws on each of turns 1–3.

Driftwood exposes a `reroll_reward_card` action for each eligible generated
card-reward group. Each group retains its generator metadata and independent
one-use state through snapshots and forks. Encounter offers use the pinned
encounter rarity generator and advance the stored rarity offset; supported
prototype-pool, Rare-pool and distinct event offers reroll through the reward
stream. Deferred Neow card offers, Dream Catcher rest rewards and Glory Trial
offers use the same reward continuation. Custom fixed-card choices without a
card-reward generator are not rerolled. Native RNG parity remains open. The
pinned relic is
[`Driftwood.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Relics/Driftwood.cs)
(SHA-256 `898c11b70a4d2c3fb89257a751d5d92e0abb87c13cfac6b92af59c7a12d30cd5`).

Implementation update (2026-10-12): Sand Castle is registered as an explicit
Ancient relic fixture. Its acquisition upgrades six distinct eligible deck
instances at most, preserves other card-instance fields, and upgrades all
eligible cards when fewer than six remain. An empty candidate list grants the
relic without changing the deck or consuming randomness. Touch of Orobas is
eligible only with Silent's Ring of the Snake; acquisition replaces that
instance in place with Ring of the Drake and persists both source relic IDs on
the acquired Touch instance. Both effects use the current prototype acquisition
path; source `run.niche` ownership and native seeded parity remain open. These
dependencies alone do not enable Orobas or normal Ancient assignment.

Archaic Tooth is eligible only while Silent's Neutralize remains in the deck.
Acquisition transforms the first eligible instance in deck order into Suppress,
keeping its instance ID, upgrade level, enchantment, and persistent card state.
The Tooth instance records both card IDs and the transformed instance ID; this
fixed transformation consumes no random draw. Other characters' Ancient card
mappings and native acquisition parity remain open.

Alchemical Coffer adds four potion slots and fills those new slots using four
distinct rarity-weighted potions from the currently implemented potion pool.

four empty slots without consuming potion-generation draws. The complete
source potion pool and any native replacement/offer continuation remain open;
this partial dependency does not enable Orobas. Its pinned source is
[`AlchemicalCoffer.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Relics/AlchemicalCoffer.cs)
