# Native Silent card rarity odds in Act 1 Overgrowth

The pinned v0.111.0 `CardRarityOdds` starts at a **-5 percentage point**
rare offset and persists across encounters and shops. Every generated
encounter-reward card rolls independently; rare resets the offset to -5 points,
while any other rarity raises it by +1 point on A0–A6, capped at +40 points.
Ascension 7 (Scarcity) changes the growth to +0.5 points and lowers the base
rare probability.

| Source | A0–A6 rare base | A7+ rare base | Uncommon base | Advances offset |
| --- | ---: | ---: | ---: | --- |
| Regular encounter | 3% | 1.49% | 37% | Yes |
| Elite encounter | 10% | 5% | 40% | Yes |
| Boss encounter | 100% | 100% | 0% | Yes; resets |
| Merchant | 9% | 4.5% | 37% | No |

All percentages except the boss's rare chance are adjusted by the run's
current offset. Scarcity thresholds use the pinned `AscensionLevel.Scarcity = 7`.
When a tier is empty, `CardFactory.GetNextAllowedRarity` wraps
Common → Uncommon → Rare → Common. The offset update uses the
*initially rolled rarity* and therefore precedes tier fallback.

The native-structure Overgrowth run now stores
`RunWorldState.CardRarityOffsetBasisPoints`, generates every combat
card-reward group sequentially from that state, and lets shops read it without
altering it. Merchant rarity consumes the reward stream, while merchant
card selection and upgrade checks consume the shop stream. The source also
performs a reward-stream upgrade check for every generated combat reward card;
the Act 1 baseline chance is zero.

This remains a *source-shaped* approximation: discrete integer sampling and
the restricted Silent pool replace native floating-point PRNG encoding,
unlock-state filtering and future hooks. Other prototype region/act
generation retains its existing weights.
