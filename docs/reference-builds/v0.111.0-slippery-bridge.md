# v0.111.0 Event: Slippery Bridge

Target: v0.111.0 / 41cef1ea, audited source
`Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`.

Source: [`SlipperyBridge.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Events/SlipperyBridge.cs).

After floor 6, the event is eligible when the deck has a removable card. It
highlights a removable card; overcoming the bridge removes that card. Holding
on costs 3 HP initially, then one additional HP for each repeated attempt,
and rerolls a removable card of a different type where possible. Repeated
holding continues in a loop page. The route registers the event in Overgrowth,
Underdocks, Hive, and Glory.

The emulator keeps the highlighted card and skipped-card set in event state
so saves and forks preserve the loop. If no non-Basic removable card remains
on entry, it falls back to any removable card. Native event RNG call parity
and UI hover details remain unverified.
