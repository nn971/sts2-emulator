# v0.111.0 mechanics gap 146 — Happy Flower trigger timing

The pinned Happy Flower advances its saved counter at each owner side-turn
start. Every third start, it grants 1 energy. The source hook is
`AfterSideTurnStart`, and it only counts turns where its owner is a participant.

The emulator now counts `PlayerSideTurnStarted` events in persistent relic
state and grants the energy on every third event, carrying the count between
combats. This event runs after energy reset and before hand draw in the
configured automatic pipeline. The prototype does not expose the source display
counter or activation visual, and no new executable coverage claim is recorded.
