# v0.111.0 mechanics gap — pass 016

This pass adds generic player-debuff blocking, with Artifact versus Spectral Knight's Hex as the
acceptance case.

## Native evidence

Hex is a Debuff. Artifact blocks the next Debuff applied to the player and consumes one Artifact
stack instead.

For Spectral Knight this means:

- opening Hex is prevented;
- no Hex power instance is created;
- no card becomes Hexed;
- exactly one Artifact stack is consumed;
- Spectral Knight proceeds into its normal Soul Slash / Soul Flame loop rather than retrying Hex.

## Generic power metadata

`PrototypePowerDefinition` now separates two capabilities:

- `IsDebuff` — applying this positive stack count is an incoming player Debuff;
- `BlocksNextDebuff` — one stack of this power can cancel one incoming Debuff application.

Hex declares `IsDebuff`.

The prototype Artifact power declares `BlocksNextDebuff`.

The engine does not branch on either power ID.

## Application ordering

Debuff blocking occurs inside the ordinary player-power application path before:

- a power instance is created or stacked;
- source-enemy ownership is recorded;
- source-bound card Afflictions are applied;
- any other source-bound card transformation runs.

That ordering matters for Hex. A blocked Hex therefore leaves no partial source state to clean up
later and no transient Hexed cards.

Source-bound powers still validate that the caller supplied an enemy source before entering this
path; malformed source-bound applications are not hidden by Artifact.

## Artifact consumption

When a positive Debuff is about to land, the engine chooses the earliest-applied active
`BlocksNextDebuff` power.

One stack is consumed:

- a one-stack blocker is removed;
- a multi-stack blocker remains with its stack count decremented by one.

The blocker keeps its application identity when stacks remain.

Only powers explicitly marked as Debuffs enter this path. Ordinary positive player powers, such as
Footwork applying Dexterity, do not consume Artifact.

## Tests

Focused coverage verifies:

- two Artifact stacks block Spectral Knight's opening Hex and leave one stack;
- no Hex source power is created;
- no card receives Hexed from the blocked application;
- Spectral Knight continues to Soul Slash next turn rather than retrying Hex;
- an ordinary positive player power does not consume Artifact.

## Remaining frontier

Artifact now blocks the modeled player Debuff path, but the prototype does not yet expose a full
native taxonomy for every status/power application that may count as a Debuff.

The next Knight Gang case is Magi Knight's Dampen. It is useful because it combines:

- source-bound ownership;
- non-stacking multi-caster behavior;
- Artifact blocking;
- mutation of existing card Upgrade state;
- restoration only after the last source dies;
- a special Nightmare interaction for cards generated after Dampen landed.
