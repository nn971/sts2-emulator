# v0.111.0 mechanics gap 144 — Blood Vial trigger timing

The pinned Blood Vial hook runs at late player-turn start. It heals its owner
for 2 only when `PlayerCombatState.TurnNumber <= 1`, so the relic heals on the
first player turn of each combat. It is a Common shared relic.

The emulator now triggers the 2 HP heal from `PlayerTurnStarted` on combat turn
1. In the current automatic turn pipeline that event follows the hand draw,
which keeps the healing at the late start-of-turn boundary. The normal
`HealPlayer` effect caps HP at Max HP. The engine does not model visual/audio
effects from the source command, and no new executable coverage claim is
recorded.
