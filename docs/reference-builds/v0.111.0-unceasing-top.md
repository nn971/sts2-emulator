# v0.111.0 Shared Relic: Unceasing Top

Target: v0.111.0 / 41cef1ea, audited source
`Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`.

Source: [`UnceasingTop.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Relics/UnceasingTop.cs).

Unceasing Top is Rare. When its owner's hand becomes empty during one of the
valid player turn phases, it draws a card. The emulator wires a player-side
CardPlayed trigger that draws one card when that play leaves the hand empty,
and includes the relic in the Silent shared pool and Rare queue.

The source's turn-phase gate is not represented in the prototype combat
state. Autoplay timing and exact native draw RNG remain fidelity gaps.
