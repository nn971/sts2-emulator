# v0.111.0 mechanics gap 084 — Nutritious Soup

Nutritious Soup is an Act 2 Tezcatara reward. Tezcatara offers it in the first
relic group when the deck contains a basic Strike. Acquiring Soup applies
Tezcatara's Ember to every eligible unenchanted basic Strike, including
upgraded copies, while preserving existing enchantments and card identity.

Executable coverage opens Tezcatara until Soup appears with a basic Strike,
checks that a deck without one cannot receive the offer, and validates the
persisted event stream. It then exercises the relic-acquisition hook across
eligible, upgraded, already-enchanted and non-Strike cards, plus a melted
copy. Cost and damage semantics remain part of the wider combat verification;
native RNG parity remains unverified.
