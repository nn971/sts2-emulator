# Morphic Grove event audit

Target: single-player STS2 v0.111.0 / source commit
`706ef1c9fa2219220065849fd5265328607ece20`.

The pinned [`MorphicGrove.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Events/MorphicGrove.cs)
has source SHA-256
`1a1f37cdab4f130ca7556226417414612fa6e547d95f653341a5d8b8cb8553a4`. The
event is eligible when the player has at least 100 gold and two transformable
deck cards. Group loses all gold and opens two persistent-card transform
choices. Loner grants 5 Max HP. Both choices now retain their terminal result
page before the map resumes.

The complete source branch inventory has seven paths:

| Source path | Behavior |
| --- | --- |
| `page/INITIAL` | Present Group and Loner. |
| `initial/GROUP` | Lose all gold and choose two cards to transform. |
| `page/INITIAL/GROUP` | Resolve the initial Group choice. |
| `page/GROUP` | Show the Group result and return to the map. |
| `initial/LONER` | Gain 5 Max HP. |
| `page/INITIAL/LONER` | Resolve the initial Loner choice. |
| `page/LONER` | Show the Loner result and return to the map. |

Transformation selection and event completion are integrated. Transform-pool
selection still uses the prototype RNG and is not a native parity claim.
