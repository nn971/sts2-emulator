# v0.111.0 mechanics gap 065 — Red Mask

Pinned `RedMask.cs` is a Common shared relic. Before the owner's first side
turn, it applies 1 Weak to every hittable enemy. The emulator registers it in
the Common pool and uses the opening `PlayerSideTurnStarted` trigger to apply
Weak to all enemies on turn 1.

Coverage checks Common-pool membership and the first-turn all-enemy Weak
effect.
