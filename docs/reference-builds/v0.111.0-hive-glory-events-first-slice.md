## Implemented events

**Hive Bugslayer** (previously registered but forced-fixture only).
Two choices: Extermination adds Exterminate to the persistent deck;
Squash adds Squash. The native source immediately ends the event
after the one chosen card is acquired.

**Hive Infested Automaton.** Study adds one random Silent Power from
the available reward pool. Touch Core adds one randomly chosen Silent
card with canonical zero energy cost, excluding X-cost. Both preserve
card identity and route the card through the common acquisition hooks,
then complete the room. Source uses `CardFactory.CreateForReward`,
including rarity and card-pool rules; we currently draw uniformly
within the eligible source-shaped subset using the emulator event RNG.
Native rarity/call-order parity is still unverified.

**Glory Reflections.** Touch a Mirror downgrades up to two distinct
upgraded persistent cards, then upgrades up to four distinct eligible
cards (the second candidate list is evaluated *after* downgrades).
Shatter copies each original persistent card, including original
upgrade levels, state and enchantments, then adds one **Bad Luck**
(Eternal, Unplayable, non-upgradable curse; 13 unblockable unpowered
damage at turn end while held). Copied cards receive new persistent
instance identifiers, preserve their own state payloads and run the
existing acquisition hooks.

## Integration

Configured Silent Hive and Glory event rooms and unknown rooms use the
explicit source-backed subset. The source-shaped Unknown-room odds
still choose Combat / Treasure / Shop / Event independently, but an
Event outcome draws only the supported IDs: Hive Bugslayer or Infested
Automaton, Glory Reflections. Each can appear at most once; an exhausted
supported pool fails with a `NotSupportedException`, not a legacy or
invented event. No unrelated prototype Act 1 events can be sampled.

The complete pinned Hive and Glory event lists have many more events
with unique relics, mandatory deck selections, transformed cards,
events-with-combat, relic pickups and multiplayer-only branches.
This implementation does **not** claim native event distribution,
all-events completion, native RNG stream parity or full-run fidelity.
The availability of unimplemented events remains an explicit coverage
gap, and event pool selection is not a correct training prior until
those events and eligibility predicates are modeled.

The original v111 Act 1 event policies and legacy prototype mode are
unchanged. Existing forced encounter Weight=0 registrations are likewise
untouched.

## Verification

Tests cover curated event routing for both acts, deterministic
Unknown→Event, two Bugslayer deck results, Power/zero-cost native
Silent filters, Reflections' downgrade/upgrade and full-deck
duplication semantics, Bad Luck card flags/damage, fork and snapshot
stability, once-per-run pool exhaustion with clean rollback and
continued map progression.

Next: native `RoomSet` event bag and `IsAllowed` predicates,
additional event relics/cards and multi-page actions; then Ancients,
event reward hook parity and capture-backed route verification.
