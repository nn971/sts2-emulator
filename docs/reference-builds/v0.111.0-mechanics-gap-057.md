# v0.111.0 mechanics gap 057 — Sword of Stone and Sword of Jade

Pinned `SwordOfStone.cs` stores an elite victory count on each relic instance.
The fifth elite victory replaces that Sword of Stone with Sword of Jade in the
same relic slot. Pinned `SwordOfJade.cs` grants its owner 3 Strength when a
combat starts. Sunken Statue grants Sword of Stone through the Overgrowth
`grab` choice and the Underdocks `sword` choice.

The emulator now declares the relic ID and elite threshold on Sword of Stone's
definition. The shared persistent combat-end handler advances each active
instance's counter on elite victories and applies the configured in-place
transformation at the threshold. Coverage checks both Sunken Statue offers,
the five-win transformation metadata, and Sword of Jade's Strength trigger.

This is mechanics coverage; native combat event timing and RNG parity remain
for the later fidelity audit.
