# v0.111.0 mechanics gap 142 — Miniature Tent rest-site options

The pinned source places Miniature Tent in the shared relic pool with Shop
rarity. At a rest site, its owner can choose the remaining rest-site options;
after a choice, the game removes only that option instead of clearing the
whole option list. Relevant source blobs:

The emulator adds Miniature Tent to the shared Shop relic queue. During a rest
visit, it tracks each used option, keeps the player in the rest phase while
other legal options remain, and completes the room when none remain. The
selected option remains consumed while a rest-site reward is being resolved.
Without Miniature Tent, the first selected option still completes the visit.

Executable coverage checks pool membership and Shop rarity, then heals and
uses one Smith option during the same visit. It confirms the heal and Smith
options are consumed once, the visit continues to the remaining Train option,
and the room completes when Train is used.
Reproduce with `python tools/check_v111_coverage.py` after building the Release
CLI.
