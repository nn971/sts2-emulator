# v0.111.0 later-act normal formation additions

Pin: `Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`;
game v0.111.0 / 41cef1ea.

- `Encounters/TunnelerNormal.cs`: native encounter contains a Chomper
  with `ScreamFirst = true`, followed by a Tunneler. The registered
  `screech-first` Chomper slot reuses the tested native move-state branch.
- `Encounters/ConstructMenagerieNormal.cs`: one PunchConstruct
  followed by *two* CubexConstructs. Each has its own HP, block, AI and
  combat instance ID, reusing already registered enemy definitions.

Tunneler Normal is catalogued by the pinned source but has no Act assignment
and is absent from Hive's `GenerateAllEncounters`; it remains a forced fixture.
Construct Menagerie is in Glory's native roster and is included in the opt-in
Glory queue despite its generic `Weight=0`. Existing Punch/Cubex combat models
are still prototype models, not individually validated v111-native semantics.

The additional Glory normal registrations use source-backed monster
mechanics: Axebot (Stock/respawn), Fabricator (spawn pool, conditional
summon), Globe Head (Galvanic/affliction), and The Lost and Forgotten
(possessed Strength/Dexterity). They are selected by the opt-in Glory queue;
native RNG streams and live-game parity remain unverified.

Owl Magistrate Normal is registered in `PrototypeNativeGloryNewNormals`:
231/247 HP, 16/17 Scrutiny, 4×6 Peck, Soar at turn three,
33/36 Verdict applying Vulnerable 4 and removing Soar. Its typed
Soar power halves powered attack damage while active, leaving
ordinary HP loss unchanged. Synthetic source-backed tests cover the
move registry and damage hook; native parity is not claimed.

## Remaining Glory source-backed combat slices

Axebots Normal, Globe Head Normal, Owl Magistrate Normal, The Lost
and Forgotten Normal, and Fabricator Normal are implemented and integrated
in the opt-in Glory pool; `FrogKnightNormal`,
`SlimedBerserkerNormal` and `ScrollsOfBitingNormal` came in
previous slices. They retain `Weight=0` in the generic selector to keep the
default profile gated; the experimental route draws from a separate prepared
queue.

Fabricator uses `FabricatorNormal.cs`, `Fabricator.cs`,
`Zapbot.cs`, `Stabbot.cs`, `Guardbot.cs`,
`Noisebot.cs` and `HighVoltagePower.cs` from the source pin.
The boss starts alone in central `fabricator` slot and chooses
between two summon actions until 4 living teammates. The
defensive pool is Guardbot/Noisebot; the aggressive pool is
Zapbot/Stabbot. The preceding bot type is excluded when
choosing its successor. The native spawn slots are bot1,
bot2, fabricator, bot3, bot4. Each bot has its own HP, power,
move and instance ID, and is a minion. The source uses
`RunRng.MonsterAi` for bot type selection, whereas this
prototype fixture uses the existing combat stream.

Remaining release gaps: native action/animation timing,
cross-power hooks, exact source pool/draw ordering, reference RNG ownership
and live-game parity.
