# v0.111.0 mechanics gap 149 — Vambrace and card reward relics

The pinned shared relic pool contains four relics missing from the emulator:
Dingy Rug, Unsettling Lamp, Vambrace, and Wing Charm. They are now registered
in the shared relic pool with their native rarities. Vambrace doubles Block
gained from the first owner card to gain Block in combat, including later
Block from that card before its play finishes. Unsettling Lamp doubles debuff
power applied by the first eligible owner card in combat and spends its trigger
after that card completes. Dingy Rug adds available Colorless cards to ordinary
combat, Rest Site heal and Orrery card rewards. Its pool carries into Driftwood
rerolls and Lasting Candy's bonus Power options. Wing Charm uses the native run
`niche` stream to give Swift to a random eligible option in combat, Rest Site
heal, Orrery, and rerolled card reward groups.

Colorless offers are limited to the emulator's implemented, reward-eligible
single-player Colorless cards. Wing Charm's fallback prototype RNG path uses
the event stream when native run RNG ownership is disabled; event-owned card
reward surfaces are not yet included. The combat model does not yet retain
native temporary-power source relationships, so Unsettling Lamp's
temporary-power double-dip exception is not represented. These paths have no
executable coverage claim yet.
