Petrified Toad is an Uncommon shared relic. Before each combat it tries to add
a Potion Shaped Rock. The token potion targets one enemy and deals 15 damage
without an empowered Attack modifier. Procurement leaves the relic inactive
when potion acquisition is prevented or no slot is open.

Potion Shaped Rock is excluded from ordinary reward, shop, and random potion
pools, matching its token pool. The emulator performs the procurement at
combat setup; native hook ordering and RNG parity remain unverified.
