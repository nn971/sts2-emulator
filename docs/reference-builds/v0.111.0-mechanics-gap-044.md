# v0.111.0 mechanics gap 044 — Silent card batch 1

This pass promotes five cards from catalog-only metadata to executable combat mechanics:

- Calculated Gamble
- Expose
- Outbreak
- Storm of Steel
- Strangle

## Source pin

The rules reference is the v0.111.0 source snapshot at
`Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`.

## Reusable engine work

### Whole-hand discard continuation

`DiscardHand` is now a combat effect. It moves the current hand to discard without creating a
player decision, dispatches `CardDiscarded` events in hand order, auto-plays Sly cards through the
existing Sly path, and preserves nested choices plus the remainder of the originating card-play
series. The count-dependent effects for Calculated Gamble and Storm of Steel are captured when the
card effects are enqueued, before the hand is discarded.

### Immediate enemy-status trigger

`TriggerEnemyStatus` invokes the status's native trigger semantics immediately. Poison uses
unblockable HP loss and decrements only while the poisoned enemy survives. Outbreak applies Poison
to all living enemies first and then triggers each target once.

### Enemy power/block utilities

Cards may now clear enemy Block and remove an enemy power by identity. Enemy-applied debuff powers
also consume Artifact through the same generic blocker used by status debuffs.

### Enemy-owned triggered powers

Effect targeting can address the enemy that owns the triggering power. Strangle uses this together
with the existing pre-play power-application ceiling: newly applied Strangle does not trigger on
itself, while older Strangle instances do. Strangle HP loss bypasses Block and the power expires at
the end of the enemy turn.

### Upgrade-only Retain

Card definitions can now grant intrinsic Retain only after upgrade. Calculated Gamble is the first
production user.

## Card semantics

- **Calculated Gamble**: 0-cost Uncommon Skill; discard the rest of the hand, then draw that many;
  Exhaust; upgrade adds Retain.
- **Expose**: 0-cost Uncommon Skill; remove all target Block, remove Artifact, apply 2 (3) Vulnerable;
  Exhaust.
- **Outbreak**: 3-cost Rare Skill; apply 9 (12) Poison to all enemies, then trigger their Poison.
- **Storm of Steel**: 1-cost Rare Skill; discard the rest of the hand, then create that many Shivs;
  upgraded copies are upgraded.
- **Strangle**: 1-cost Uncommon Attack; deal 8 (10), apply 2 (3) Strangle. Existing Strangle deals
  its stored amount after each player card play and expires at enemy-turn end.
