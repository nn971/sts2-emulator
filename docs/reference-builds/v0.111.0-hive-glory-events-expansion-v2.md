# v0.111.0 Hive and Glory event expansion: Lost Wisp, Colossal Flower, Round Tea Party

Pin: build v0.111.0 (`41cef1ea`), mirror
`Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`.

Source event classes: `LostWisp.cs`, `ColossalFlower.cs`,
`RoundTeaParty.cs`. Supporting classes:
`Models/Cards/Decay.cs`, `Models/Relics/LostWisp.cs`,
`Models/Relics/PollinousCore.cs`,
`Models/Relics/RoyalPoison.cs`.

## Source-shaped semantics implemented

- **Hive Lost Wisp**: a single event RNG roll yields 45–75
  Gold (60 ±15 inclusive). Search takes it; Claim adds the
  **Decay** curse and the **Lost Wisp** relic. Decay is unplayable,
  non-upgradable and inflicts 2 **blockable**, unpowered HP damage
  from the hand at player-turn end. The relic deals 8 unpowered
  damage to all living enemies after each Power card played.
- **Hive Colossal Flower**: gated by HP ≥19 before entering.
  Three prize depths (0/1/2): 35/75/135 Gold. The first two
  `Reach Deeper` selections inflict 5 and 6 unblockable damage.
  At depth 2, take 135 Gold or take 7 unblockable HP damage
  and acquire the **Pollinous Core** relic. All three pages and
  illegal page transitions are explicit event states.
  Pollinous Core counts `BeforeHandDraw` occurrences in saved
  player relic state and grants **two extra draw cards on each
  fourth hand draw**, resetting to zero and retaining counts
  across combats, snapshots and forks.
- **Glory Round Tea Party**: gated by HP ≥12. `Enjoy Tea` gives
  **Royal Poison** and heals fully. `Pick Fight` first enters a
  confirmation page and then `Continue Fight` deals 11
  unblockable damage and obtains the next relic from the
  existing source-shaped grab bag. Royal Poison deals 4
  **unblockable** self-damage at the first player-turn start.
  Combat `DamagePlayer` now has an explicit opt-in
  `IgnorePlayerBlock` flag: existing damage effects retain
  their previous semantics.

## Explicit limitations

This adds 2 Hive events and 1 Glory event to the earlier curated
set, for **4 Hive and 2 Glory** supported event models. Native
`RoomSet` event selection, full source eligibility and rarity
priors, and native RNG stream/call order remain unverified. The
current event selector is **not** a native distribution.
Unavailable event models never fall back to legacy/prototype
events; once the curated pool is exhausted, the room fails
explicitly. An end-to-end three-act win is therefore not yet
guaranteed.

The current relic grab bag and HP-damage pipeline approximate
native order when several relics modify the same events.
Event relics are deliberately not inserted into ordinary
reward/shop pools. Multiparty behavior and cross-character
event rewards are out of scope.

## Regression coverage

The expanded test suite checks event act gates, eligible HP
thresholds, all three Colossal Flower prize states, page-specific
choice legality, fixed damages, relic acquisition, Lost Wisp
random-gold redemption, curse/card flags, Royal Poison and Lost
Wisp trigger declarations, Pollinous Core's counter and JSON
persistence. It also exercises the live combat card-damage
and source-shaped run-map infrastructure from prior slices.

Next candidates: Hungry for Mushrooms, Spirit Grafter, Zen Weaver,
Grave of the Forgotten and the multi-branch Trial, with native
card/relic/enchantment support before enabling each event.
