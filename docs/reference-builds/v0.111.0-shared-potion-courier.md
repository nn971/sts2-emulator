# Potion Courier event audit

Target: single-player STS2 v0.111.0 / source commit
`706ef1c9fa2219220065849fd5265328607ece20`. Potion Courier is integrated
into the Hive and Glory event pools.

The pinned [`PotionCourier.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Events/PotionCourier.cs)
has source SHA-256
`af833f2f25684a2b869748cfbaf1a96e54a10d03d17fadfc33d996dadf61c832`. Grab
Potions queues three Foul Potions through the event reward prompts. Ransack
offers one random Uncommon potion from the implemented Silent/shared subset.
Each completed choice leaves a result page before returning to the map.

Foul Potion deals 12 damage to every enemy and 12 damage to the player in
combat. At a shop, it can instead be thrown at the Merchant for 100 gold. The
event branches and ordinary Merchant use are implemented; the fake-Merchant
interaction is not modeled. Ransack's selection pool and random stream do not
claim native RNG parity.

The complete source branch inventory has seven paths:

| Source path | Behavior |
| --- | --- |
| `page/INITIAL` | Present Grab Potions and Ransack. |
| `initial/GRAB_POTIONS` | Choose three Foul Potion rewards. |
| `page/INITIAL/GRAB_POTIONS` | Resolve the initial Grab Potions choice. |
| `page/GRAB_POTIONS` | Show the Grab Potions result and return to the map. |
| `initial/RANSACK` | Choose one random Uncommon potion reward. |
| `page/INITIAL/RANSACK` | Resolve the initial Ransack choice. |
| `page/RANSACK` | Show the Ransack result and return to the map. |

The event's complete branch inventory and pool integration are coverage
claims, not live-game certification.
