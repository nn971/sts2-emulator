# v0.111.0 mechanics gap 053 — Big Mushroom

Pinned `BigMushroom.cs` is an Event relic offered by the Act 3 Hungry for
Mushrooms event. On pickup it grants 20 Max HP and heals 20. It also reduces
the owner's hand draw by two on turn one of each combat.

The emulator expresses the pickup reward as a `RelicAcquired` run trigger, so
the event's normal relic acquisition callback grants the Max HP and healing.
The existing first-turn draw modifier remains active for the acquired relic.
