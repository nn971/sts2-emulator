Akabeko is Uncommon. At the start of its owner's first side turn, it grants
8 Vigor. Vigor adds one damage per stack to each hit of the next powered
attack command owned by that creature, then removes the stacks captured when
that command began.

The emulator includes Akabeko in the shared Silent relic pool and the
Uncommon relic bag. Its trigger runs on the first PlayerSideTurnStarted
event and applies 8 stacks of the existing Vigor power. Card-backed player
attacks receive the additive damage, and the power is consumed after the
attack card completes. Terror Eel's source-shaped Vigor move uses the same
power on the enemy side.

The combat model does not yet cover Vigor on cardless powered attack
commands. Source trigger timing and native run parity remain unverified.
