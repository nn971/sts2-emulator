# v0.111.0 mechanics gap 052 — Royal Poison

Pinned `RoyalPoison.cs` is an Event relic. On its owner's first player turn
in each combat, each active copy deals 4 unblockable, unpowered damage to the
owner. Round Tea Party's `enjoy_tea` choice grants the relic and heals the
player to full.

The emulator records the opening HP loss on the relic definition and applies
it at combat opening. The combat-entry hook counts active relics, so melted
copies do not trigger. The shared HP-loss reducer also applies Tungsten Rod's
reduction to this damage.
