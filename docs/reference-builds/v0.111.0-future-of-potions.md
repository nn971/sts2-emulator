# The Future of Potions

This event is implemented for the configured Silent route through the Hive
and Glory. The implementation follows the pinned source at
[`TheFutureOfPotions.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Events/TheFutureOfPotions.cs)
(blob SHA-256 `f1b22a8e138d8710afcdc85cf40b666bfad719b8b6232522a0249a7ad77fca44`).

## Pinned behavior

- The event is allowed when the player owns at least two potions.
- On first option generation, the source rolls an Attack, Skill, or Power
  category for every owned potion. Common and Token potions cannot roll Power.
  The event displays up to the first three potions in potion-slot order.
- Choosing one potion discards it. The event creates a noncombat reward with
  three cards from the player's character pool, filtered by both the mapped
  card rarity and the saved card category. It disables rarity and card-pool
  modifications, upgrades the generated cards, then finishes the event after
  the reward resolves.
- Common and Token potions map to Common cards, Uncommon maps to Uncommon, and
  Rare and Event map to Rare. The pinned [PotionRarity enum](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Entities/Potions/PotionRarity.cs)
  includes all six tiers.

The local rarity mapping uses the supported Silent/shared potion catalogue,
plus the source Event potions Foul Potion, Ambergris, and Glowwater, and Blood
Potion's Common rarity. The pinned definitions are
[Foul Potion](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Potions/FoulPotion.cs),
[Ambergris](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Potions/Ambergris.cs),
[Glowwater](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Potions/GlowwaterPotion.cs), and
[Blood Potion](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Potions/BloodPotion.cs).

## Emulator behavior

`proto.native.shared.the_future_of_potions` is registered once per run in both
later-act event lists and is eligible with two or more supported potions.
Event-entry offers store the potion slot, potion ID, card category, and target
rarity in `EventState`; forks preserve that state. Trading consumes the saved
slot and creates the three-card reward. Its generator metadata carries both
rarity and card type, so Driftwood rerolls stay within the same filtered pool.
The reward also consumes one Silver Crucible group charge when applicable and
marks its options upgraded. The completed event page remains available until
the player continues to the map.

Native v111 runs persist `THE_FUTURE_OF_POTIONS` event context for the
entry-time card-type rolls; the legacy profile retains prototype `event` RNG.
Seeded result/cursor parity, profile unlock filtering, reward alternative
behavior, and live reward-hook ordering remain part of the later fidelity
review. The coverage report records the source branches as implemented and
integrated; native parity remains unverified. A Release solution build and the
coverage-baseline checker were run for the original implementation. No tests
were run for this RNG migration.
