# v0.111.0 mechanics gap — pass 036

This pass promotes **Inklet**, adds the reusable **Slippery** HP-loss modifier, and completes the
three-Inklet Overgrowth normal formation.

## Slippery

Pinned behavior:

- each stack affects the next positive HP-loss event on the enemy;
- that HP loss is capped to exactly 1;
- one Slippery stack is then consumed;
- a hit fully absorbed by Block causes no HP loss and therefore does not consume Slippery.

The implementation models this as a generic enemy-power HP-loss modifier rather than an Inklet-only
special case.

The modifier is applied after enemy Block absorption and before enemy HP is reduced.

The same helper is also used for direct enemy HP loss from retaliation and enemy status-stage damage,
so the representation follows the power text's "loses HP" boundary rather than only card attacks.

This primitive is intentionally reusable for Vantom later in the Overgrowth boss pass.

## Inklet model

Pinned v0.111.0 values:

- HP 11–17 at A0–A7;
- HP 12–18 at A8+;
- Jab: 3 damage, 4 at A9+;
- Whirlwind: 2 damage x3, 3 x3 at A9+;
- Piercing Gaze: 10 damage, 11 at A9+;
- starts with 1 Slippery.

## Source-shaped move program

The three encounter slots have distinct openers:

- left outer Inklet: Jab;
- middle Inklet: Whirlwind;
- right outer Inklet: Jab.

After that, each Inklet alternates between:

1. Jab;
2. an equal random choice of Piercing Gaze or Whirlwind;
3. Jab;
4. another equal random choice;
5. and so on.

The encounter uses semantic slot names `left`, `middle`, and `right` only as emulator-side
formation labels. They are not claimed to be native serialized slot identifiers.

## Encounter formation

`INKLETS_NORMAL` now contains exactly three Inklets at formation positions 0, 1, and 2.

The slot labels feed the existing generic `SlotNameEquals` conditional AI predicate, so the enemy
definition contains one source-shaped opener rule rather than three duplicated enemy definitions.

## Regressions

Focused tests verify:

- A0/A8 HP ranges;
- A9 scaling for all three moves;
- one starting Slippery stack;
- exact left/middle/right formation and opener behavior;
- both Gaze and Whirlwind are reachable after Jab;
- both random followups return to Jab;
- fully blocked damage leaves Slippery intact;
- the next real HP loss is capped to 1 and consumes Slippery;
- retaliation HP loss passes through the same Slippery modifier.
