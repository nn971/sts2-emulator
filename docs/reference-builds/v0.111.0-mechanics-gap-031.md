# v0.111.0 mechanics gap — pass 031

This pass promotes **Fuzzy Wurm Crawler** as a source-backed Act 1 model and adds its singleton
Overgrowth weak reference encounter.

## Fuzzy Wurm Crawler

Pinned v0.111.0 values:

- HP 55–57 at A0–A7;
- HP 58–59 at A8+;
- Acid Goop: 4 damage, 6 at A9+;
- Inhale: gain 7 Strength.

The source move program is a fixed three-state cycle:

1. Acid Goop;
2. Inhale;
3. Acid Goop;
4. repeat from step 1.

The two Acid Goop positions reference the same move definition from two distinct AI states. This
preserves one semantic move identity while representing the source graph exactly.

## Ascension representation

The A8 HP range is asymmetric:

- minimum 55 -> 58;
- maximum 57 -> 59.

The typed enemy definition therefore uses independent minimum and maximum Ascension deltas instead
of approximating the range with one shared offset.

A9 changes the Acid Goop base damage by +2. Inhale remains +7 Strength.

## Strength interaction

Inhale uses the existing generic enemy Strength power.

The focused cycle regression verifies:

- turn 1 Acid Goop deals 4;
- turn 2 Inhale deals no damage and adds 7 Strength;
- turn 3 Acid Goop therefore deals 11;
- turn 4 is the first Acid Goop of the next cycle and still benefits from the retained Strength.

This also confirms that the three-state loop, rather than a two-state alternating approximation, is
represented.

## Reference encounter

`FUZZY_WURM_CRAWLER_WEAK` is represented as a weight-0 singleton reference encounter at formation
position 0.

As with the other promoted weak formations, weight 0 keeps native encounter-pool selection as a
separate fidelity claim.
