# v0.111.0 mechanics gap — pass 040

This pass begins the **Overgrowth elite** layer by promoting the two elites whose mechanics are
already fully expressible with existing generic primitives: **Bygone Effigy** and **Byrdonis**.

The native elite pool is not activated yet. Phrog Parasite still has a death-summon timing subtlety
that should be pinned before the three-entry pool is enabled.

## Bygone Effigy

Pinned v0.111.0 values and pattern:

- HP 127 at A0–A7;
- HP 132 at A8+;
- starts with Slow;
- turn 1: Sleep, no effect;
- turn 2: Wake, gain 10 Strength;
- turn 3 onward: Slashes every turn;
- Slashes base damage 13, 15 at A9+.

Because the +10 Strength is permanent, the first actual Slashes attack deals 23 at A0–A8 and 25 at
A9+ before player-side mitigation.

### Slow

The existing generic Slow representation is exercised directly:

- every card played this turn contributes another +10% incoming Attack-card damage;
- the bonus is applied only to Attack-card damage;
- integer rounding floors naturally.

The focused regression uses two 6-damage Slice attacks in one turn:

- first attack at one card played remains 6 after flooring;
- second attack at two cards played deals 7.

The turn-scoped card counter already resets through the generic turn pipeline, so no Effigy-specific
state is required.

## Byrdonis

Pinned v0.111.0 values and pattern:

- HP 81–84 at A0–A7;
- HP 90 at A8+;
- starts with Territorial 1;
- fixed Swoop -> Peck -> Swoop -> ... pattern;
- Swoop: 17 damage, 19 at A9+;
- Peck: 3 x3, 4 x3 at A9+.

### Territorial

Territorial uses the existing generic enemy end-of-turn Strength hook.

At the end of each Byrdonis turn it gains 1 Strength. This means the regression observes:

1. first Swoop for 17, then Strength becomes 1;
2. Peck deals 4 x3 because the existing Strength is added to each hit, then Strength becomes 2;
3. next Swoop deals 19, then Strength becomes 3.

No Byrdonis-specific combat code is needed.

## Next work

Pin Phrog Parasite's Infested death-summon timing precisely.

The important distinction is not the monster values or Wriggler pattern—they are already represented.
The unresolved question is the first-turn stun boundary:

- when Phrog dies during the player turn, newly spawned Wrigglers are already considered stunned for
  that enemy phase and begin their Bite/Wriggle patterns on the following enemy turn;
- when Phrog dies during enemy-turn damage such as Poison/Thorns, their first skipped action falls on
  the following player/enemy cycle instead.

The emulator currently has one unconditional `SkipNextEnemyAction` flag for death summons. That is
too coarse to claim native parity. The next pass should make summon timing phase-aware, then promote
Phrog and activate the three-entry Overgrowth elite bag.
