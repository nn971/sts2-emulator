## Progress since pass 004

### Dynamic cost and Pinpoint

The engine now supports count-derived fixed Energy costs.

Pinned **Pinpoint** is represented as:

- 3 Energy;
- Uncommon Attack;
- 15 (+4) damage;
- costs 1 less for each Skill already played this turn;
- minimum cost 0.

The cost is recomputed both when legal actions are enumerated and when the action executes.

### Per-card draw events

Drawing is no longer only a pile mutation. Each successfully drawn card dispatches a
`CardDrawn` event and increments the combat-wide draw counter.

The event records whether the draw belongs to the normal start-of-turn hand draw. Power triggers
can independently filter:

- all card draws;
- non-hand-draw card draws;
- draws that happen during the active player turn.

This supports pinned:

- **Corrosive Wave** — each card drawn this turn applies 2 (+1) Poison to all enemies;
- **Speedster** — each qualifying card drawn during the player's active turn deals 2 damage to all
  enemies; upgrade adds Innate rather than changing the damage.

### Delayed next-turn effects

The ruleset now has explicit stages for next-turn effects rather than resolving them at one generic
turn-start point.

Temporary carrier powers can currently contribute:

- Block immediately after normal Block clear;
- Energy immediately after normal Energy reset;
- extra hand draw at the normal hand-draw stage;

and then remove themselves at the corresponding stage.

This represents pinned:

- **Dodge and Roll** — gain 4 (+2) Block now and the same amount next turn;
- **Sidestep** — next turn gain 1 (+1) Energy;
- **Predator** — deal 15 (+5) damage and draw 2 additional cards next turn.

This ordering matters because these effects interact differently with Block reset, Energy reset,
hand capacity and draw-reactive powers.

### Pounce and one-shot card-type cost overrides

Static source for native `FreeSkillPower` establishes:

1. it changes the cost of owner Skills in Hand/Play to 0;
2. non-Skills do not consume it;
3. `BeforeCardPlayed` decrements one stack when a qualifying Skill is played.

The prototype now has a generic power policy:

- `FreeCardType`;
- `ConsumeOnMatchingCardPlay`.

Pinned **Pounce** is represented as:

- 2 Energy;
- Uncommon Attack;
- deal 14 (+6) damage;
- the next Skill played costs 0.

The one-shot power is consumed before the Skill's effects resolve. The same consumption path is also
used for Sly auto-play, so a qualifying auto-play cannot silently preserve the modifier.

The exact native general energy-cost modifier stack remains broader than this first typed policy;
this change deliberately models the source-backed one-shot family rather than a global cost system.

### Anticipate and temporary Dexterity

Pinned **Anticipate** is now represented as:

- 0 Energy;
- Common Skill;
- gain 2 (+2) Dexterity for the current turn.

The current emulator representation uses a temporary power with the same card-Block modifier as
Dexterity and removes it at `PlayerTurnEnded`.

This is behaviorally correct for current Block calculations and keeps permanent Dexterity separate.
It is not yet a full model of native `TemporaryDexterityPower`, which internally applies real
`DexterityPower` and later reverses that amount. That distinction can matter to future
power-introspection hooks and is recorded as a known fidelity limitation rather than hidden.

### Before-hand-draw is now an explicit event boundary

Static `InfiniteBladesPower.BeforeHandDraw` shows that Infinite Blades creates its Shiv **before**
the normal hand draw rather than at the later player-turn-start hook.

The engine now dispatches `BeforeHandDraw` immediately before calculating/drawing the normal hand.
This preserves hand-cap interactions: a generated Shiv can occupy a hand slot and reduce the number
of ordinary cards drawn.

Pinned **Infinite Blades** is represented as:

- 1 Energy;
- Uncommon Power;
- before each normal hand draw, add 1 Shiv to Hand per stack;
- upgrade adds Innate.

A regression case uses eight retained cards to distinguish before-hand-draw timing from a later
turn-start approximation.

### Suppress

Pinned **Suppress** requires no new primitive:

- 0 Energy;
- Ancient Attack;
- Innate;
- deal 11 (+6) damage;
- apply 3 (+2) Weak.

Its Ancient rarity naturally keeps it out of the ordinary reward pool.

## Static-source lesson from this pass

The useful unit of reverse engineering is increasingly a **hook or modifier family**, not a card.

Examples now represented generically include:

- random target per hit;
- draw-card event;
- active-player-turn filter;
- before-hand-draw hook;
- count-derived cost;
- one-shot card-type cost override;
- turn-scoped power expiry;
- next-turn Block/Energy/draw carriers.

Cards that use these mechanisms are mostly data once the primitive exists.

## Current high-value frontier

### 1. Card replay / play-count modifiers

Pinned **Burst** is the next major structural target.

Native `BurstPower` modifies the card play count before the card starts resolving and decrements
one stack after participating in that modification. Native `CardModel` then executes the complete
per-play lifecycle once for each play index:

- `BeforeCardPlayed`;
- card-play-start history;
- `OnPlay`;
- enchantment/affliction play effects;
- card-play-finish history;
- `AfterCardPlayed`.

A faithful generic replay primitive therefore cannot merely duplicate the card's scalar effects.
It must replay nested choices and per-play hooks while paying/moving the card only once.

This is why Burst is intentionally deferred until the continuation model can represent repeated
whole-card executions.

### 2. Hand-local and card-local cost mutation

Remaining examples:

- **Bullet Time** — cards currently in Hand become free this turn, plus No Draw;
- **Up My Sleeve** — this individual card permanently reduces its own combat cost after each play.

These need combat-card-local cost state rather than another player-wide fixed-cost special case.

### 3. Turn-scoped global modifiers

Examples:

- Blur — preserve Block into the next turn;
- Shadowmeld — double Block gain this turn;
- Piercing Wail — temporary Strength reduction;
- Wraith Form — Intangible plus recurring Dexterity loss.

These should use explicit modifier/value provenance instead of card-name checks.

### 4. Start-turn choices and delayed selected-card effects

Examples:

- Tools of the Trade — draw then discard at turn start;
- Nightmare — remember a selected card and create copies next turn.

The current automatic event dispatcher deliberately rejects triggers that suspend for a player
choice. That boundary should be generalized before importing these cards.

### 5. Card-local temporary keyword mutation

Examples:

- Expertise — drawn cards gain temporary Retain;
- Hand Trick — selected Skill gains temporary Sly;
- Master Planner — played Skills acquire Sly.

Combat-card state exists, but keyword overrides need a typed representation and cleanup policy.

### 6. Remaining aggregate/value-query effects

Examples:

- Mirage — Block equal to total Poison across enemies;
- Accuracy — Shivs gain damage;
- Tracking — Weak enemies take additional Attack damage;
- Phantom Blades — first Shiv each turn gains bonus damage.

These should extend the existing typed count/predicate/value layer rather than introduce named card
branches.

## Recommended next implementation order

1. combat-card-local cost overrides, beginning with Up My Sleeve;
2. temporary hand/card cost changes and No Draw, then Bullet Time;
3. whole-card replay continuation, then Burst;
4. Block-preservation and generic turn-scoped modifiers;
5. automatic hooks that can suspend for player choices;
6. card-local keyword overrides;
7. aggregate status/value queries.

No reference-bridge update or game restart is justified by the current frontier.
