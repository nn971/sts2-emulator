# Hive Colossal Flower event audit

Target: single-player STS2 v0.111.0 / source commit
`706ef1c9fa2219220065849fd5265328607ece20`.

The pinned [`ColossalFlower.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Events/ColossalFlower.cs)
has source SHA-256
`ca0ee1f25d200ea85ddfe301965370d20e7930606409956c22c2317b2622c0d3`. The
event is eligible at 19 or more HP. Each Reach Deeper choice deals 5, 6, then
7 unblockable and unpowered damage. The first two pages offer the current gold
prize (35, then 75) or another dig. On the third page the player chooses 135
gold or Pollinous Core after taking the final 7 damage. Every final option calls
`SetEventFinished`; the result page remains visible until continuation.

The complete source branch inventory has fourteen paths:

| Source path | Behavior | Verification |
| --- | --- | --- |
| `page/INITIAL` | Present the first gold extraction or deeper dig. | `ColossalFlowerExtractsStageSpecificGold` checks both legal choices and runs extraction at each stage; `FlowerThirdDigPaysSevenHpAndGrantsRelicInsteadOfGold` exercises the full digging route. |
| `initial/EXTRACT_CURRENT_PRIZE_1` | Choose the 35-gold first-page prize. | `ColossalFlowerExtractsStageSpecificGold` checks the payout and finished result page. |
| `page/INITIAL/EXTRACT_CURRENT_PRIZE_1` | Resolve the first-page extraction. | Same test validates HP, gold, result page, invariant state, and snapshot restore. |
| `initial/REACH_DEEPER_1` | Take 5 unblockable damage and reveal the second page. | `ColossalFlowerExtractsStageSpecificGold` checks the damage and page index. |
| `page/INITIAL/REACH_DEEPER_1` | Show the second page after the first dig. | Same test checks that the next legal choices are extraction or another dig. |
| `page/REACH_DEEPER_1` | Present the 75-gold prize or second dig. | Same test checks stage-two choice legality and payout. |
| `page/REACH_DEEPER_1/EXTRACT_CURRENT_PRIZE_2` | Choose the 75-gold prize. | Same test checks the gold total and accumulated 5 damage. |
| `page/REACH_DEEPER_1/REACH_DEEPER_2` | Take 6 damage and reveal the third page. | `FlowerThirdDigPaysSevenHpAndGrantsRelicInsteadOfGold` checks cumulative 11 damage and the final choice set. |
| `page/REACH_DEEPER_2` | Present 135 gold or Pollinous Core. | Same test checks both final choices after the two digs. |
| `page/REACH_DEEPER_2/EXTRACT_INSTEAD` | Choose 135 gold instead of Pollinous Core. | Same test checks the 235-gold total and 8 HP before explicit continuation. |
| `page/REACH_DEEPER_2/POLLINOUS_CORE` | Take 7 damage and obtain Pollinous Core. | Same test checks 1 HP, relic acquisition, no gold, and explicit continuation. |
| `page/EXTRACT_CURRENT_PRIZE` | Show a first- or second-page extraction result. | `ColossalFlowerExtractsStageSpecificGold` checks the 35- and 75-gold result pages. |
| `page/EXTRACT_INSTEAD` | Show the third-page extraction result. | `FlowerThirdDigPaysSevenHpAndGrantsRelicInsteadOfGold` checks the 135-gold result page. |
| `page/POLLINOUS_CORE` | Show the relic result. | Same test validates snapshot restore, invariants, and deterministic fork continuation. |

`PrototypeNativeHiveEventFlow` preserves the finished choice and result page;
`PrototypeRooms` allows only `continue_event` on that page and records the map
room after continuation. The native event does not roll a prize or relic here,
so this branch audit does not claim live RNG parity or native certification.
