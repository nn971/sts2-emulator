# v0.111.0 mechanics gap — pass 025

This pass adds formation-aware conditional enemy AI and promotes **Toadpole** as a source-backed
Act 1 monster model.

## Formation-order state

`EnemyCombatState` now carries a typed `FormationPosition`.

The emulator convention is:

- lower formation positions are closer to the front;
- front is recomputed over living enemies;
- instance ID is a deterministic tie-breaker only;
- native encounter translation is responsible for assigning source-backed positions.

This is deliberately a simulation convention rather than a claim that the pinned encounter JSON
contains native slot coordinates. The pinned structured encounter corpus lists participating monster
models but omits multiplicity and slot layout for encounters such as Toadpoles and Nibbits.

Normal prototype combat construction currently assigns formation positions from encounter enemy
order. Future native encounter definitions can replace that provisional ordering without changing
conditional-AI semantics.

## Conditional enemy AI

The source-shaped AI state graph now supports a third state kind, `Conditional`, alongside
`Move` and `Random`.

Typed first predicates are:

- `IsAlone`;
- `IsFront`;
- `IsNotFront`.

Conditional branches are ordered. The first matching branch targets a normal move state, after which
the existing move state's follow-up transition continues normally.

A synthetic regression verifies:

- alone takes precedence when listed first;
- front/back predicates distinguish formation positions;
- a rear enemy becomes alone/front when an earlier living slot disappears.

This matches the shape of the pinned Nibbit and Toadpole source conditions without embedding
monster-specific tests into the engine.

## Toadpole

Pinned v0.111.0 structured values:

- HP: 21–25 at A0–A7, 22–26 at A8+;
- Spike Spit: 3×3 damage, 4×3 at A9+;
- Whirl: 7 damage, 8 at A9+;
- Spiken: gain 2 Thorns.

Its source-shaped initial state is conditional:

- not front -> Whirl;
- front -> Spiken.

After the opener, each chosen move enters the fixed cycle represented by the pinned state graph:

- Spike Spit -> Whirl;
- Whirl -> Spiken;
- Spiken -> Spike Spit.

Focused tests verify two simultaneous Toadpoles choose different front/back openers and that the rear
Toadpole becomes front when an earlier formation slot is dead.

## Encounter boundary

This pass promotes the **Toadpole monster model**. It does not promote `TOADPOLES_WEAK` encounter
formation or pool semantics.

The pinned encounter table identifies Toadpole as the participating model but does not encode the
number of Toadpoles or native slot coordinates. Those claims remain pending source/oracle evidence.
