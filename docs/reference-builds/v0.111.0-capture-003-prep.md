## Why Knight Gang

Passes 015–021 made Knight Gang the first source-backed native encounter in the prototype:

- Spectral Knight / Hex;
- Artifact blocking;
- Magi Knight / Dampen;
- Flail Knight constrained random moves and Strength;
- complete A0 encounter composition;
- typed A8/A9 Ascension scaling.

The highest-value next step is therefore differential validation rather than adding more static
content.

## Probe v3

The bridge remains passive:

- no gameplay method patching;
- no RNG advancement;
- no action injection.

Relative to previous probes, v3 adds/refines:

- enemy Creature and Model runtime type catalogs;
- current/next move projection when readable;
- intent/current-intent projection when readable;
- move index, last move and move-history projection when readable;
- card Affliction projection;
- Enchantment/card-modifier projection;
- additional Upgrade fields useful for observing Dampen;
- all existing player/enemy HP, Block, powers, pile contents, CombatHistory and native serialized
  RNG snapshots.

Reflection failures leave fields absent rather than generating guessed values.

- lifecycle sequence/boundary;

- native monster-AI RNG path/value evidence and a deterministic fingerprint of that evidence.

## Static comparison already available

At the first native checkpoint, observed Knight max HP is compared against
`PrototypeContent` using the captured Ascension.

This is intentionally the only automatic emulator substitution currently made, and it is reported
as an explicit static comparison rather than being presented as native evidence.

Missing Ascension or missing max-HP fields produce a skipped comparison/diagnostic rather than an
assumed value.

## RNG policy

The audit fingerprints **native** monster-AI RNG evidence but does not compare it numerically with
the emulator's prototype SplitMix stream.

Until the native RNG codec and call schedule are reconstructed:

- a different but legal Flail Knight sequence is not proof of a mechanics bug;
- an illegal repeat is a mechanics bug;
- a fixed Magi/Spectral sequence mismatch is a mechanics bug;
- missing native RNG evidence is an instrumentation gap.

This distinction is formalized in
`v0.111.0-knight-gang-differential.md`.

## What happens after the capture

The first audit will classify discrepancies into:

1. **mechanics mismatch** — patch the emulator and add a native-derived regression;
2. **observability gap** — minimally enrich the passive recorder;
3. **RNG-only gap** — begin reconstruction of native monster-AI RNG codec/call order without
   changing enemy mechanics.

This is now the blocking step for stronger Knight Gang fidelity claims.
