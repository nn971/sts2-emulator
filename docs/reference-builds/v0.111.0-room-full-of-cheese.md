# v0.111.0 Event: Room Full of Cheese

Target: v0.111.0 / 41cef1ea, audited source
`Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`.

Sources: [`RoomFullOfCheese.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Events/RoomFullOfCheese.cs)
and [`ChosenCheese.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Relics/ChosenCheese.cs).

The event is allowed in the first two source act regions, represented by the
Overgrowth and Underdocks profiles. Gorge offers eight Common cards from the
current character's card pool and adds exactly two selected cards. Search costs
14 HP and grants Chosen Cheese, which adds 1 Max HP after each victorious
combat.

The emulator persists the eight card offers through its event reward phase and
prevents selecting the same offered card instance twice. Its available card
pool contains currently implemented Silent Common cards; full pool generation,
relic-trigger ordering, and native RNG parity remain for the fidelity pass.
