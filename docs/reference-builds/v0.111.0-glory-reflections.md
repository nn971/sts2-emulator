# Glory Reflections event audit

Target: single-player STS2 v0.111.0 / source commit
`706ef1c9fa2219220065849fd5265328607ece20`.

The pinned [`Reflections.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Events/Reflections.cs)
has source SHA-256
`728bfd3c6044fc0a04411285a5e811e6b518d981e21257941b44f872f87e066e`. Touch a
Mirror downgrades up to two distinct upgraded cards, recomputes the eligible
pool, then upgrades up to four distinct upgradable cards. Shatter copies only
the original deck, preserves card state and enchantments with new instances,
adds Bad Luck, and finishes the event. Both outcomes leave a completion page.

The complete source branch inventory has seven paths:

| Source path | Behavior | Verification |
| --- | --- | --- |
| `page/INITIAL` | Present Touch a Mirror and Shatter. | `NewEventCataloguesAndEventOnlyContentAreGated` checks the pinned choice IDs. |
| `initial/TOUCH_A_MIRROR` | Choose Touch a Mirror. | `ReflectionsMirrorUsesTwoDistinctDowngradesThenFourUpgrades` checks the downgrade and recomputed upgrade pass. |
| `page/INITIAL/TOUCH_A_MIRROR` | Resolve the card changes. | Same test checks the terminal choice ID, result page, invariants, and snapshot round-trip. |
| `page/TOUCH_A_MIRROR` | Show the mirror result and return to the map. | Same test explicitly continues and checks map choice. |
| `initial/SHATTER` | Choose Shatter. | `ShatterCopiesOnlyOriginalDeckAndPreservesIdentityPayload` checks the original deck is copied once and Bad Luck is added. |
| `page/INITIAL/SHATTER` | Resolve the copies and curse. | Same test checks instance allocation, copied upgrade/enchantment state, invariants, and snapshot round-trip. |
| `page/SHATTER` | Show the Shatter result and return to the map. | Same test explicitly continues and checks map choice. |

`PrototypeNativeGloryReflectionsTeaParty` applies the choices, then
`PreserveNativeEventCompletionPage` stores the source terminal choice. Native
v111 runs persist the `REFLECTIONS` event-local context across both sequential
selection passes; the legacy profile retains the prototype `event` stream.
Seeded result/cursor parity remains open. This audit does not claim live-game
certification.
