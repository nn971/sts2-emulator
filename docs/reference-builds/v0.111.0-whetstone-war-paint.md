# v0.111.0 Shared Relics: Whetstone and War Paint

Target: v0.111.0 / 41cef1ea, audited source
`Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`.

Sources: [`Whetstone.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Relics/Whetstone.cs)
and [`WarPaint.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Relics/WarPaint.cs).

Both are Common shared relics. On acquisition, Whetstone randomly upgrades
up to two upgradable Attacks; War Paint does the same for Skills. They are
registered in the Silent shared relic pool and common rarity queue.

The emulator filters by card type and upgrade eligibility, shuffles the
candidates, and upgrades up to two. It uses the prototype event RNG stream;
native `Rng.Niche` shuffle parity remains open.
