# v0.111.0 mechanics gap 104 — Strike Dummy

Strike Dummy is a Common shared relic. It adds 3 damage to every powered
Attack whose card has the Strike tag. Melting it disables the bonus.

Executable coverage checks a Strike-tagged Attack, a non-Strike Attack, and a
melted copy through the powered-attack damage modifier. The damage bonus runs
per hit, so it also applies to multi-hit Strike-tagged attacks.
