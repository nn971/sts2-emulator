# v0.111.0 experimental Silent three-act route integration

This is a **new, explicit experimental fidelity mode**:
`v111-experimental-silent-three-act-route-v1`. The pinned static source
remains `Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`,
with the native structured source pin recorded in
`docs/FULL_IMPLEMENTATION_ROADMAP.md`.

## Integrated execution boundary

A configured Silent Act 1 run (Overgrowth or Underdocks) can continue past
its boss reward to a generated Hive map and then to a Glory map. Both maps use
`PrototypeNativeLaterActMap.GenerateNative` and the pinned act-local map
streams, with persistent player state, history, profile, original prototype
run streams and native 15-stream ownership retained across the transitions.

The initial two-encounter-per-tier slice has been extended by
[the regional integration batch](v0.111.0-regional-integration-bags.md).
The experimental route now selects from **all 20 Hive and all 18 Glory**
native encounter registrations. Native act classes specify **two** initial
weak ordinary fights, then normal encounters. The act-local weak, normal
and elite pools use persistent without-replacement bags and an act-entry
preselected boss, rather than picking arbitrary registered fixtures.

Hive has 9/10 executable regional events (Colorful Philosophers depends on
deferred cross-character card acquisition); Glory has 7/7. Unknown rooms
now use the same native-shaped, persistent and per-act-reset pity weights as
Overgrowth. Combat rewards, shops and treasures reuse the source-shaped
rarity/potion/relic economy. **Those odds and native RNG stream ownership
remain provisional, and this does not make all-seed natural runs or native
parity proven.**

## Invariants and regression scope

- Configured v111 non-experimental runs continue to reject native later-act
  execution.
- The three-act experimental route requires a source-shaped Hive/Glory map
  matching the configured act, clears Act 1 region/encounter bags, and
  retains persistent card/relic/potion identity and all RNG cursors.
- Floor and completed-room validation use the correct Act 1/2/3 boss floors.
  Active named later-act encounters are limited to the native catalogued regional pool;
  there is no unrestricted `Weight=0` registration fallback.
- Focused tests exercise both transitions, deterministic RNG and JSON
  snapshot preservation, ordinary regional combat entry and stateful unknown
  event routing, plus the unmodified default hard gate.

## Remaining before a trustworthy production route

1. Audit native encounter/event weights, availability history and exact RNG; source-shaped regional bags and rewards are integrated but not reference matched.
2. Source-audit later-act boss interrupts, player-choice continuations and
   enemy/ally death processing on full runs.
3. Replace the prototype RNG in card shuffling, combat effects, shops,
   rewards and event generation with native ownership/call order.
4. Replay actual end-to-end reference traces and run multi-seed CI sweeps,
   checking both successful victory and terminal defeat without fixture
   mutation.

**Evidence label:** implementation/integration experiment with synthetic
checks. Native gameplay fidelity and full event/encounter coverage remain
unverified. No game assets or decompiled code are redistributed.
