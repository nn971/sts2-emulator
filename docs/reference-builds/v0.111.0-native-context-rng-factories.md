# Native v0.111.0 context-specific gameplay RNG constructors

Target: STS2 `v0.111.0 / 41cef1ea`, executable snapshot
`Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`.

Implementation: `NativeRngV111Contexts`, alongside the existing independent
`NativeRngV111` SplitMix64/xoshiro256** codec.

## Ownership and derivation

All formulas are interpreted in 64-bit unsigned arithmetic with wraparound.
`S` denotes `RunRngSet.Seed` (the numeric run seed), and `H(x)` is
`xxHash64(UTF8(x), 0)`. Every listed context has a **fresh mutable RNG
instance** that must be kept for the duration of its native owner.

| Context | Source call site | Constructor seed |
| --- | --- | --- |
| Act map | `StandardActMap.CreateFor` | `S + H("act_{CurrentActIndex+1}_map")` |
| Encounter formation | `EncounterModel.GenerateMonstersWithSlots` | `S + TotalFloor + H(Encounter.Id.Entry)` |
| Monster-specific RNG | `CombatState.CreateCreature` | `S + (MapCoord?.col ?? 0) + (MapCoord?.row ?? 0) + CurrentActIndex + CombatId` |
| Event-local RNG | `EventModel.Begin` | `S + (IsShared ? 0 : OwnerSlotIndex) + H(Event.Id.Entry)` |
| Player-content RNG | `Rng(Player, ModelId, mixin)` | `S + PlayerSlotIndex + H(ModelId.Entry) + mixin` |

`ForActMap` accepts a *one-based* act number (1/2/3);
`ForMonster` accepts the native *zero-based* act index (0/1/2).
Native identifiers must be passed exactly as their model `Id.Entry`, with
their original spelling and case. For event/monster contexts without map
coordinates, native uses zeroes. Repeated event entries reproduce the same
initial event stream; different `mixin` values can distinguish repeated
content instances. The additive seeds can collide in intentionally different
contexts (for example, one extra player slot versus one extra mixin).

The emulator stores an active event's context stream in
`EventState.NativeEventRng`, independently of the persistent run/player
bundle. Current migrated sites include Trash Heap (`TRASH_HEAP`), Tablet of
Truth (`TABLET_OF_TRUTH`), Doors of Light and Dark
(`DOORS_OF_LIGHT_AND_DARK`), Fake Merchant (`FAKE_MERCHANT`), Tinker Time
(`TINKER_TIME`), Stone of All Time (`STONE_OF_ALL_TIME`), Battleworn Dummy
(`BATTLEWORN_DUMMY`), Hungry for Mushrooms (`HUNGRY_FOR_MUSHROOMS`),
Reflections (`REFLECTIONS`), Trial (`TRIAL`), The Future of Potions
(`THE_FUTURE_OF_POTIONS`), Infested Automaton (`INFESTED_AUTOMATON`),
Endless Conveyor (`ENDLESS_CONVEYOR`), This or That (`THIS_OR_THAT`), Lost
Wisp (`LOST_WISP`), and Punch Off (`PUNCH_OFF`); their source-seeded result
and cursor parity remain
open in the
[migration matrix](../DESIRED_RNG_MIGRATION_STATUS.md).

## Regression and use

`NativeRngV111ContextTests` checks hard-coded initial xoshiro state
vectors for all five cases, using independent `libxxhash` calculations
followed by SplitMix64 expansion; also verifies act and floor changes,
event sharing, source-owner slot/mixin equivalences, context isolation,
serializable counters and forked continuation.

A caller owns the returned `RngStreamState` and may place it in a
`RngBundle` for `NativeRngV111.NextInt`, `Shuffle` and
`ToSnapshot`/ `FromSnapshot` operations. Context-specific streams are
**separate** from the persistent 12 run and 3 player streams. Their
identifiers carry context metadata for debugging, rather than representing
new `RunRngType` values.

The current gameplay engine still uses six legacy prototype streams.
This batch establishes exact context constructors only. Native fidelity
requires storing each context stream with its owner and migrating each
generator's call site and ordering. In particular: map generation uses a
separate temporary RNG, monster intent selection uses `run.monster_ai`,
monster unique HP uses `run.niche`, and the monster's own effects can use
its per-creature stream. Synthetic vectors establish seed/codec agreement;
real-game reference traces are needed for cross-boundary RNG parity.

To execute focused tests:

```fish
dotnet test Sts2Emulator.sln -c Release --filter FullyQualifiedName~NativeRngV111ContextTests
```
