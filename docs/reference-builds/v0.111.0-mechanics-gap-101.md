# v0.111.0 mechanics gap 101 — Tiny Mailbox

Tiny Mailbox is an Uncommon shared relic. Choosing Rest offers two random
potions as separate optional rewards. They can be taken into free slots,
replace a held potion, or be skipped. Melted copies do not trigger. Smith and
other rest-site options do not proc it.

The rest reward path integrates these potion offers with other post-Rest
rewards such as Dream Catcher card groups. Executable coverage takes the Rest
action, checks both potion offers, accepts one, and verifies a melted copy
produces no reward. It also checks the shared pool and Uncommon rarity.
