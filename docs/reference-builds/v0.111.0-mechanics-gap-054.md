# v0.111.0 mechanics gap 054 — Fragrant Mushroom

Pinned `FragrantMushroom.cs` is the other Event relic from Act 3 Hungry for
Mushrooms. Its pickup deals 15 unblockable, unpowered damage, then upgrades
two different upgradable cards when available.

The emulator applies the HP loss through the relic's acquisition trigger,
including Tungsten Rod's reduction. The Hungry for Mushrooms handler checks
for defeat before selecting upgrades and chooses distinct card instances up
to the relic's configured count.
