# v0.111.0 mechanics gap 046 — Silent card batch 2

This pass promotes three more native Silent cards from metadata-only entries to executable combat
mechanics: Accelerant, Malaise, and Shadow Step.

## Accelerant

Accelerant is a 1-energy Uncommon Power granting 1 (2) Accelerant. Enemy status triggering now has
a generic extra-trigger query. For Poison, each Accelerant stack adds one trigger, capped by the
current Poison amount. Both ordinary enemy-turn Poison and explicit triggers such as Outbreak use
the same path.

## Malaise

Malaise is an X-cost Rare Skill with Exhaust. It applies -X Strength and X Weak; the upgrade uses
X+1 for both. Negative Strength applications are represented as debuffs for Artifact purposes while
the Strength power itself remains a signed counter.

## Shadow Step

Shadow Step costs 1 (0), discards the rest of the hand, and stores one Shadow Step counter. At the
start of the next player turn, that counter becomes an equal-duration Double Damage power and the
stored Shadow Step power removes itself. Double Damage multiplies powered card attacks by two and
decrements at player-turn end.

The whole-hand discard path introduced in pass 045 is reused directly, including CardDiscarded and
Sly semantics.
