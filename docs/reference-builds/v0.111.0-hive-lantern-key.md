## Implemented behavior

- Return the key completes the event and credits exactly 100 Gold.
- Keep the key reveals a required Fight follow-up page.
- Fight starts a forced single-enemy Mysterious Knight combat, reusing the
  source-shaped Flail Knight move state graph and starting Strength 6 plus
  Plating 6.
- Solo enemy Plating grants 6 Block at combat entry, adds its remaining
  stacks of Block at the enemy-side turn end, and decays one stack from
  the second enemy-side start onward.
- On victory, a dedicated optional special-card reward offers a new
  unplayable, unupgradable Quest-rarity Lantern Key. Take, skip and
  room completion preserve the event continuation.
- The event and special encounter retain `Weight=0` in the generic registry;
  the experimental route selects the event from its Hive event list, and the
  event starts its named fight directly.

## Known gaps

- Lantern Key changes Glory Unknown-room routing and forces the
  War Historian Repy event there. This carryover is integrated in the
  experimental route; native map/event RNG parity remains open.
- Native solo HP sampling, precise event and monster RNG ownership,
  runtime trigger ordering and UI reward skip mechanics remain
  unverified against a game oracle.
- Default configured Hive/Glory routes remain gated. Experimental event
  selection includes Lantern Key, but its event and combat RNG are not native
  trace validated.
- No native gameplay trace exists for this fixture; tests are
  deterministic emulator regressions only.

The patch does not treat the later quest as completed or claim live parity.
