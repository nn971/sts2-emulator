# The Architect ending

The configured Silent route now enters The Architect after the final Glory
boss reward. The pinned event source is
[`TheArchitect.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Events/TheArchitect.cs)
(blob SHA-256 `3d3ea8889b71d0781a0d6bc06ed2db2c5c6786dfeefbfe9f7bfa4503af70149a`).

## Pinned Silent behavior

The Architect selects dialogue using the character's prior wins. Silent has
four visit-indexed dialogue entries, each with one line, followed by Proceed.
Proceed calls `RunManager.WinRun()`. The source's
[`TheArchitectEventEncounter.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Encounters/TheArchitectEventEncounter.cs)
(blob SHA-256 `f23a77c49ebdefe04fc08cc77033b6179acb7f11003acd01c70bae87d584b1c3`)
provides the Architect as a scene creature; it does not run a combat.

## Emulator behavior

After a configured v111 Silent run resolves its last Glory boss reward, the
engine enters a one-choice The Architect event. Proceed records terminal
victory. The event links to a zero-weight event-scene encounter containing a
9999 HP Architect actor, so the pinned scene encounter is represented in
content metadata without making it a map or combat offer. The dialogue text,
prior-win selection, and animations are not modeled in the headless state.
This event is a run-ending step, not an ordinary Glory event-pool entry.
