# v0.111.0 mechanics gap 139 — Silent Orrery acquisition

The pinned source includes Orrery in the shared relic pool and gives it Shop
rarity. On pickup, it offers five separate `CardReward`s, each with three
cards generated from the owner's character pool using regular-encounter
rarity odds. Orrery advertises an upon-pickup effect, so it is not tradable.

The emulator now registers Orrery in the shared relic pool and Shop rarity
queue. Acquisition generates five independent three-card groups from the
supported Silent reward pool using the regular-encounter rarity generator.
Each card retains its upgrade result, and each group can be selected or
skipped independently. The generator metadata also keeps Orrery groups
available to the existing Driftwood reroll path. A custom reward continuation
preserves and resumes the room or reward interrupted by the pickup. Orrery is
excluded from the Relic Trader through typed acquisition-reward metadata.

Coverage acquires Orrery through a relic reward, checks all five groups and
their card-pool, generator, and upgrade metadata, takes and skips groups, and
verifies that the original reward resumes. Native RNG consumption for all
fifteen card offers is not yet verified; the current implementation reuses the
existing encounter-card generator, so this does not claim full native replay
parity. Reproduce with `python tools/check_v111_coverage.py` after building the
Release CLI.
