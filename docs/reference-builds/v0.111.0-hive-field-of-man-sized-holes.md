# Hive Field of Man-Sized Holes event audit

Target: single-player STS2 v0.111.0 / source commit
`706ef1c9fa2219220065849fd5265328607ece20`.

The pinned [`FieldOfManSizedHoles.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Events/FieldOfManSizedHoles.cs)
has source SHA-256
`2f6fcabc64b998eb55c266f1fd2907659d071e419fa41b131ab16d0a4106c5f1`. The
event is eligible when the deck contains a card that can receive Perfect Fit.
Resist removes up to two selected deck cards, adds Normality, and finishes the
event. Enter Your Hole lets the player enchant one eligible card with Perfect
Fit and then finishes the event. Each branch leaves the completion page open
until continuation.

The complete source branch inventory has seven paths:

| Source path | Behavior | Verification |
| --- | --- | --- |
| `page/INITIAL` | Present Resist and Enter Your Hole. | `SourceEligibilityAndGatedEventRegistration` checks the source option IDs and eligibility. |
| `initial/RESIST` | Select Resist and begin removal of two cards. | `ResistRemovesTwoDeckCardsThenAddsNormality` checks the pending count and each selected removal. |
| `page/INITIAL/RESIST` | Keep the event open while the removal prompt is unresolved. | Same test verifies Normality is not added before the required selections finish. |
| `page/RESIST` | Add Normality, show the result page, then return to the map. | Same test checks curse identity and instance allocation before explicit continuation. |
| `initial/ENTER_YOUR_HOLE` | Select the Perfect Fit option. | `EnterYourHoleEnchantsOneSelectedEligibleCard` checks the eligible-card action. |
| `page/INITIAL/ENTER_YOUR_HOLE` | Resolve the selected card enchantment. | Same test verifies only the selected card receives Perfect Fit. |
| `page/ENTER_YOUR_HOLE` | Show the finished enchantment result and return to the map. | Same test checks the result page and explicit continuation. |

The common persistent deck-choice handler owns selection and effect ordering;
`PrototypeNativeEventCompletionPages` retains both source completion pages.
Perfect Fit's combat draw ordering and Normality's held-card play limit have
separate tests in this suite. Native event cursor parity remains open.
