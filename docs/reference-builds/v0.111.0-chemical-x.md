# v0.111.0 Shared Relic: Chemical X

Target: v0.111.0 / 41cef1ea, audited source
`Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`.

Source: [`ChemicalX.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Relics/ChemicalX.cs).

Chemical X has Shop rarity. It adds 2 to the X value of its owner's X-cost
cards. The emulator already applies the relic's `XValueBonus` when resolving
X-cost effects; this update adds Chemical X to the configured Silent relic
pool and Shop queue.

The source also recognizes X star costs and flashes when either kind is
played. X star costs and the visual cue are not modeled. Shop queue RNG parity
remains unverified.
