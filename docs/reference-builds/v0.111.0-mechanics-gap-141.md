# v0.111.0 mechanics gap 141 — Lava Lamp fight rewards

The pinned source places Lava Lamp in the shared relic pool with Shop rarity.
Its owner gets each upgradable card option upgraded after a combat if they
took no unblocked, non-unblockable damage during that combat. Relevant source
blobs:

- [`LavaLamp.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Relics/LavaLamp.cs), SHA-256 `ffe3a17d65b89b10d9f6750ef2aa6273fccfe6adac2ea3412a5187af61baf242`.
- [`SharedRelicPool.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/RelicPools/SharedRelicPool.cs), SHA-256 `ed20fba34a6508cef299f8ec06bea5051e28760dbc064649ea45dfc487f7fee0`.

The emulator adds Lava Lamp to the shared Shop relic queue and records positive
player damage during combat. Victory rewards upgrade eligible options in the
base and extra card groups; the reward flag remains available to Driftwood
rerolls. The current damage event does not distinguish unblockable damage, so
that source exception remains for the later fidelity pass.

Executable coverage checks pool membership and rarity, the no-damage upgrade
path, a damage event suppressing upgrades, extra reward groups, and reroll
reapplication. Reproduce with `python tools/check_v111_coverage.py` after
building the Release CLI.
