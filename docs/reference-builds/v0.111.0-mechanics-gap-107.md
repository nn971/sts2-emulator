# v0.111.0 mechanics gap 107 — Royal Stamp

Royal Stamp is a Shop shared relic. Upon acquisition, choose one Attack or
Skill in the deck to receive the Royally Approved enchantment. The
enchantment makes the card Innate and Retain. Powers and other card types are
not eligible; if there is no eligible card, no choice is required.

Executable coverage checks the acquisition choice against Silent Strike,
Defend, and Footwork, then verifies the enchanted card is Innate and Retain.
