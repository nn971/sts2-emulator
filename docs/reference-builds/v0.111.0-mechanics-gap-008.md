# v0.111.0 mechanics gap — pass 008

This pass generalizes combat-card keyword state and uses Hand Trick and Expertise as
source-backed acceptance cases.

## Native evidence

Pinned v0.111.0 data/source establishes:

- **Hand Trick**: 1 Energy, Silent Uncommon Skill; gain 7 Block (10 upgraded), then add
  Sly to a Skill in Hand for this turn.
- **Expertise**: 1 Energy, Silent Uncommon Skill; draw 2 cards (3 upgraded), and those
  exact drawn cards gain Retain for this turn.
- Sly participates in the ordinary discard lifecycle: a Sly card discarded from Hand
  before turn end auto-plays for free.
- Retain participates in end-of-turn hand cleanup before its temporary per-turn state
  expires.

## Emulator changes

The combat-card model now has typed keyword overrides:

- Retain;
- Sly;
- Ethereal;
- explicit enabled/disabled state;
- cleanup flags for end-of-turn and when-played lifetimes.

Keyword overrides live on `CombatCardInstance` rather than on card definitions. They are
also part of `PrototypeCombatCardSnapshot`, so delayed clones such as Nightmare naturally
preserve the card-local combat state currently modeled by the prototype.

The generic choose-card primitive now supports a required card type and an optional
selected-card keyword mutation. Hand Trick is represented entirely as data over those
primitives.

The draw primitive now reports the exact card instance IDs successfully drawn. A draw effect
can attach a keyword override to precisely those instances, which represents Expertise
without querying the Hand after the fact.

End-turn handling now:

1. resolves temporary Ethereal;
2. resolves temporary or intrinsic Retain;
3. moves the remaining hand normally;
4. clears end-of-turn keyword overrides.

Sly checks likewise read effective card-instance keyword state, so a temporary Sly card
follows the same discard-autoplay path as an intrinsically Sly card.

## Tests

Coverage includes:

- Hand Trick metadata and Skill-only selection filtering;
- selected-card temporary Sly state;
- temporary Sly participating in Survivor-style discard autoplay;
- temporary Retain affecting the current end-turn discard and then expiring;
- Expertise attaching Retain only to the cards actually drawn.

The full CI suite remains green.

## Next frontier

The most useful follow-up cases are:

1. **Master Planner** — persistent Sly mutation of the Skill that generated a
   `CardPlayed` event;
2. **intrinsic Replay** — route card-local replay state through the existing whole-card
   play-series machinery;
3. **general automatic-hook suspension** — resumable event subscriber dispatch when a
   hook itself asks the player to choose;
4. **aggregate/value queries** — Mirage, Accuracy, Tracking and Phantom Blades families.

Master Planner is attractive next because it will make event subscribers able to mutate the
event's source card instance without introducing a card-name branch.
