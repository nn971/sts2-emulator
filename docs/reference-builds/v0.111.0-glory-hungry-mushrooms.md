## Source-backed event branches

The source has two immediately available choices and no
`IsAllowed` override:
- **Big Mushroom** gives an event-only relic, whose
  `AfterObtained` increases max HP by 20 (and heals 20).
  `ModifyHandDraw` subtracts two cards **only on turn one**.
- **Fragrant Mushroom** gives an event-only relic, whose
  `AfterObtained` first deals 15 unblockable/unpowered damage.
  If the player survives, it picks up to two **distinct** currently
  upgradable deck card instances and upgrades each once.
  A fatal pickup cannot secretly grant upgrades.

The event and relics are typed and the actual single-player effects are
reachable through both the experimental regional event selection and the
explicit `PrototypeNativeLaterActFixture.CreateGloryHungryForMushrooms`.
The fixture uses a full-size Glory map cursor on an Unknown node to keep
completed-room/fork state meaningful. The default configured route remains
gated from later acts; experimental selection and RNG remain provisional.

The Big Mushroom opening-hand modifier reuses the existing
first-turn relic draw sum, and affects the opening draw without
changing cards drawn on later turns. The Fragrant Mushroom upgrade
selection is sampled without replacement.

## Open fidelity gaps

- Configured Native runs use the `HUNGRY_FOR_MUSHROOMS` event context for
  `event.glory.random_upgrade.shuffle_swap_index`; Native seed derivation,
  source-call parity, and cursor parity remain open. Native-regional runs
  without `NativeRunRng` retain the legacy `event` stream. The existing
  ReferenceNature event-shuffle session admits the survivable Fragrant
  Mushroom action and commits its complete shuffle and upgrades atomically;
  this does not establish installed-game stream parity.
- These pickup effects are applied at the event's *specific*
  acquisition choice, not a general `AfterObtained` hook for
  acquisition via arbitrary external sources. Both relics are
  excluded from ordinary reward/merchant grab bags.
- Complete Glory event bag integration, exact native RNG and
  live-game trace evidence remain unverified. Coverage is partial.
