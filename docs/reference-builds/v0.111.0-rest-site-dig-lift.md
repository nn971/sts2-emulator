## Implementation

- Shovel and Girya are registered as shared relics in the common relic pool
  and the prototype bag's Rare partition.
- Shovel exposes `rest_dig`. Dig draws a relic, stores it as a one-item reward,
  and uses the normal relic acquisition path, including any acquisition-time
  deck choice. The Rest Site completes after the reward resolves.
- Girya exposes `rest_lift` while fewer than three lifts are saved. Its count
  is persisted in relic state, and the corresponding Strength is applied at
  each combat entry.
- The rest-option ID map covers Clone, Cook, Dig, Hatch, Heal, Kindle, Lift and
  Smith. Multiplayer-only Mend remains excluded.

The source blobs are not present in this checkout; the pinned inventory
provides the source identities and hashes above. Relic-bag selection currently
uses prototype RNG. Native action ordering, exact acquisition callbacks, and
RNG ownership remain fidelity follow-up work.
