# v0.111.0 Shared Relic: Juzu Bracelet

Target: v0.111.0 / 41cef1ea, audited source
`Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`.

Sources: [`JuzuBracelet.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Relics/JuzuBracelet.cs)
and [`UnknownMapPointOdds.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Odds/UnknownMapPointOdds.cs).

Juzu Bracelet is a Common shared relic. It removes Monster from the eligible
room types for Unknown map points. The emulator omits the Monster threshold;
that probability falls through to Event, while Treasure and Shop keep their
current weights. Their odds continue to increase or reset normally, while
the excluded Monster weight does not change. This applies to Overgrowth,
Underdocks, Hive and Glory maps.

The emulator uses its prototype event-stream integer roll. Native float
sampling and first-run tutorial overrides remain for later fidelity work.
The source also disallows Juzu at total floor 41 and later; that late-run
relic-offer gate is not modeled yet.
