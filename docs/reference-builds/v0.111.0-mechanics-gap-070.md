# v0.111.0 mechanics gap 070 — Blessed Antler

Blessed Antler is an Ancient relic offered by Nonupeipe in Glory. It adds one
Energy each turn and, before the first hand draw of each combat, generates
three Dazed cards at random positions in the draw pile.

Executable coverage confirms its Act 3 event choice and event-only reward path,
then dispatches `BeforeHandDraw`. It checks the three generated Dazed instances,
first-turn gating, and that a melted copy does not trigger. Native Ancient
assignment and draw-pile RNG parity remain unverified.
