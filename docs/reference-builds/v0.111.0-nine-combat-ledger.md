## Tooling increment

The passive action ledger can now cover **all numbered combats** rather
than requiring preselected elite indices:

```fish
python tools/native_overgrowth_action_ledger.py \
  '/path/to/overgrowth-silent-act1-20261008-154352-3bb5598a35f7.jsonl' \
  --all --output /tmp/native-overgrowth-all-actions.json
```

Its compact entries now retain card draws, discards, exhausts,
generation, afflictions (including card name and upgrade level),
power amounts, damage receivers, block receivers, enemy state IDs,
and combat completion markers. The original `--combats 5 6` selection
remains available. The recorder's index 0 is excluded in `--all` mode.

## Epistemic boundary and next stage

Every entry is still an **observation from an asynchronous passive
callback**. A card-play start and card-play finish delimit an observed
play, while their associated HP, block, hand/pile counts and power
snapshots can reflect intermediate modifications. Such entries must
not be interpreted as synchronized emulator-step checkpoints.
The native recorder does not supply sufficient card-instance identifiers
in its pile summaries to reconstruct a faithful exact deck/draw-order
state, and the RNG streams have not been aligned.

Suggested next implementation: a controlled native action bridge that
records legal player actions plus decision-boundary states, paired
with a test driver that injects matching visible actions into the emulator
under a declared RNG policy. Prioritize the two observed elites and
Ceremonial Beast, where this corpus supplies many high-value combat
effects. This run alone supports move/action **evidence** and targeted
regressions; it does not establish whole-run semantic parity.
