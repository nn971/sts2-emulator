# v0.111.0 mechanics gap 120 — Bowler Hat

Bowler Hat is an Uncommon relic that multiplies its owner's positive gold
gains by 1.25. `PlayerCmd.GainGold` applies relic modifiers before truncating
the decimal result to integer gold; the emulator preserves that behavior. The
relic is excluded from shops. The coverage fixture checks small, ordinary and
fractional results, Ectoplasm's gold-gain block, and a melted Bowler Hat.
It is included in the prototype's ordinary Uncommon relic pool.

The source also stops offering Bowler Hat at or after the Act 3 treasure
chest. That late-run relic-eligibility filter remains open in the prototype
pool.
