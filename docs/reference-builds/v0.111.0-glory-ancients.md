# Glory Ancient source ledger

Target: single-player STS2 v0.111.0 / build `41cef1ea`, source commit
`706ef1c9fa2219220065849fd5265328607ece20`. This ledger records the source
offer structures and implementation status. It does not claim native RNG
parity or event integration.

## Nonupeipe

Pinned source: [`Nonupeipe.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Events/Nonupeipe.cs),
SHA-256 `beaf1b558150881c7072e07b7481d1671b52489d79a4eccb2f409c5c3b9c8d0f`.

The base pool contains Blessed Antler, Brilliant Scarf, Delicate Frond,
Diamond Diadem, Fur Coat, Glitter, Jewelry Box, Looming Fruit and Signet Ring.
Beautiful Bracelet joins the pool when at least four deck cards can receive
Swift. The Ancient shuffles the eligible pool and presents three relics.
The pinned source inventory enumerates ten possible relic branches; branch
implementation is incomplete.

Signet Ring's pinned relic source is
[`SignetRing.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Relics/SignetRing.cs),
SHA-256 `77b212d016fbac660c1572338023202796dcc2c460b6faf56d1153249e602951`.
Its acquisition grants 888 gold. The emulator registers the relic and routes
that effect through the shared `RelicAcquired` trigger; a test verifies that
only the newly acquired copy grants gold. The relic is not yet offered by an
executable Nonupeipe event.

## Tanx

Pinned source: [`Tanx.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Events/Tanx.cs),
SHA-256 `d2b62cb767fa7d510f0ae4900a29bd22df0fbb933fcdaebebbd13da6c1475c56`.

The base pool contains Claws, Crossbow, Iron Club, Meat Cleaver, Sai, Spiked
Gauntlets, Tanx's Whistle, Throwing Axe and War Hammer. Tri Boomerang joins
when at least three deck cards can receive Instinct. The Ancient shuffles the
eligible pool and presents three relics. The pinned source inventory lists
ten possible relic branches; none are currently integrated into a Tanx event.

## Vakuu

The pinned source inventory lists ten possible relic branches. The offer code
uses three independent pools and presents one relic from each:

- Blood-Soaked Rose, Whispering Earring or Fiddle.
- Preserved Fog, Sere Talon or Distinguished Cape.
- Choices Paradox, Music Box, Lord's Parasol or Jeweled Mask.

The Ancient event, its three source-owned draws and all ten relic effects are
not currently integrated. In particular, Sere Talon also removes 9 maximum HP;
that acquisition side effect must be preserved along with its relic behavior.

## Remaining integration work

Run-start Ancient assignment and its `run.up_front` draw order are not
implemented. The Hive and Glory route state can open assigned Pael or
Tezcatara at Hive, but it does not assign Glory Ancients. Event availability,
source-specific RNG ownership, offer persistence, each relic acquisition path,
snapshot/fork behavior and direct branch tests remain required before any Glory
Ancient is exposed in normal regional generation. Native validation also remains
open pending a live reference corpus.
