# Glory Round Tea Party event audit

Target: single-player STS2 v0.111.0 / source commit
`706ef1c9fa2219220065849fd5265328607ece20`.

The pinned [`RoundTeaParty.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Events/RoundTeaParty.cs)
has source SHA-256
`863bcb03830443c7c2e4ed256c2287c962146f486a32346665092baa5b09d012`. The event
requires at least 12 current HP. Enjoy Tea obtains Royal Poison, heals to full,
and finishes. Pick Fight opens a separate Continue Fight page; that second
choice deals 11 unblockable, unpowered damage, grants the next relic from the
front of the persistent relic bag, and finishes. A fatal hit ends the run
before the relic is granted.

The complete source branch inventory has ten paths:

| Source path | Behavior | Verification |
| --- | --- | --- |
| `page/NOPE` | Reject the event below 12 current HP. | `GloryEventEligibilityAppliesSourceHpAndSoulsPowerConditions` checks 11 HP is ineligible and 12 HP is eligible. |
| `page/INITIAL` | Present Enjoy Tea and Pick Fight. | `NewEventCataloguesAndEventOnlyContentAreGated` checks the two source option IDs. |
| `initial/ENJOY_TEA` | Obtain Royal Poison and heal to full. | `TeaPartyEnjoyHealsToFullAndAddsRoyalPoison` checks relic and HP. |
| `page/INITIAL/ENJOY_TEA` | Resolve the initial Enjoy Tea option. | Same test validates the terminal choice and result page. |
| `page/ENJOY_TEA` | Show the finished result, then return to the map. | Same test checks invariant and snapshot round-trip, then explicitly continues. |
| `initial/PICK_FIGHT` | Choose Pick Fight. | `TeaPartyFightNeedsSecondChoiceThenDealsElevenAndGrantsOneRelic` selects it. |
| `page/INITIAL/PICK_FIGHT` | Open the follow-up page without applying effects. | Same test checks page index, unchanged HP/relic count, and state immutability. |
| `page/PICK_FIGHT` | Present Continue Fight. | Same test checks it is the follow-up action. |
| `page/PICK_FIGHT/CONTINUE_FIGHT` | Deal damage, then draw and grant one relic. | Same test checks ordered damage/relic effects; `TeaPartyFightCanKillBeforeRelicIsGranted` verifies the fatal branch. |
| `page/CONTINUE_FIGHT` | Show the finished fight result, then return to the map. | The nonfatal test validates invariant/snapshot state and explicitly continues. |

`PreserveNativeEventCompletionPage` uses page index 2 for the terminal result,
leaving page index 1 available for the intermediate fight prompt. Relic choice
uses the persistent bag, while its native draw cursor remains unaudited. No
live-game certification is claimed.
