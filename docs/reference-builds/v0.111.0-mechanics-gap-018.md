# v0.111.0 mechanics gap — pass 018

This pass adds the source-backed A0 Magi Knight.

## Native behavior represented

Magi Knight now has:

- 82 HP at A0;
- Power Shield opener: deal 6 damage and gain 5 Block;
- Dampen on turn 2;
- a repeating suffix of Ram, Prep, Magic Bomb;
- Ram deals 10;
- Prep gains 5 Block;
- Magic Bomb deals 35.

The important correction is that Magic Bomb is represented as the attack move itself, not as a
speculative delayed player debuff.

## Reuse of existing kernel

No Magi-specific combat code was needed.

The enemy definition reuses:

- opener + repeating-suffix move sequencing;
- source-bound enemy-applied player powers;
- Dampen's reversible Upgrade suppression;
- ordinary enemy damage/block effects.

Its loop starts at the Ram move, so the resulting sequence is:

`Power Shield, Dampen, Ram, Prep, Magic Bomb, Ram, Prep, Magic Bomb, ...`.

## Tests

Focused coverage verifies static A0 numbers and the first six executed turns, including Power
Shield Block, Dampen application, the first Magic Bomb, and the restart at Ram.

## Remaining boundary

Magi Knight is accurate at A0. Ascension-aware HP, Block, and damage modifiers are not yet part of
the typed run model.
