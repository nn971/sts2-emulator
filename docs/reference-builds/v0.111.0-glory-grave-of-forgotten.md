`src/Core/Models/Relics/ForgottenSoul.cs`.

## Event

`GraveOfTheForgotten.IsAllowed` checks that **at least one**
deck card can receive `SoulsPower`; the Confront option is
locked if eligibility fails. On **Confront**, native
`CardPileCmd.AddCurseToDeck<Decay>` happens *before* the one-card
enchantment selection. The selection may only target an unenchanted
card whose local keywords include **Exhaust**. Applying Souls Power
removes that keyword and saves the enchantment on the persistent card.
The typed implementation reuses the normal queued event deck-choice
protocol (including invalid-selection rejection, fork persistence and
event completion).

On **Accept**, the event obtains `ForgottenSoul`. Its existing
`CardExhausted` relic trigger deals 1 unpowered damage to one random
living enemy per qualifying event; damage is blocked normally.

The native **Decay** card is the *same class* in Hive and Glory.
We reuse `proto.native.hive.decay` with its established turn-end
2-damage blockable effect, rather than duplicate card definitions.

## Combat and inventory corrections

`SoulsPower` is a persistent card-enchantment enum member, and
the combat destination selection for both player-played and
auto-played cards now respects its removal of local Exhaust. The
same card without the enchantment still Exhausts normally and fires
`CardExhausted` relic callbacks; the enchanted card goes to discard.

The legacy prototype reward pool included `ForgottenSoul` despite
the source declaring `RelicRarity.Event`. This source audit removes
it from normal relic rolls without changing the pre-existing
`proto.relic.forgotten_soul` model and hook.

## Scope and uncertainty

All behavior here is **source-aligned, not native replay verified**.
The Glory event is reachable via the opt-in
`PrototypeNativeLaterActFixture.CreateGloryEvent` but **never**
through incomplete regional random event selection. The fixture can
deliberately force this normally ineligible event to test the locked
Confront option. It is not an example of ordinary native event
selection; a live event bag must apply IsAllowed before sampling.

The prototype engine does not model arbitrary dynamically mutated
local Exhaust keywords outside its typed `ExhaustOnUse` and
`LoseExhaustOnUpgrade` sources. The native card-selection UI
and precise RNG streams remain unverified. Cross-character
mechanics are still out of scope.
