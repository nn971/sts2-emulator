## Scope and opt-in

All **12 Overgrowth** and **10 Underdocks** native normal encounter
`GenerateMonsters()` formations now have explicitly named native model
entries in `NativeActOneNormalCombatEntryV111`. Existing
`V111Build.NativeWeakCombatEntryFidelityId` activates the experimental
native combat path for *weak and normal* encounters. The fidelity ID
retains its earlier spelling for snapshot/backward compatibility.

This work is independent of the prototype encounter selection bag
and six-stream prototype RNG. It does not switch default gameplay or
training policies to native RNG.

Each normal encounter:
1. Validates the selected source region, source-shaped map coordinate,
   selected encounter identity and run-level native RNG owner.
2. Seeds a separate native encounter-local generator from the pinned
   native `EncounterModel.Id.Entry`, the run seed and total floor.
3. Generates the precise source-shaped initial enemy identities, in
   source **creation order**, with source slot names (or null slots).
4. Records actual monster-local contexts using CombatId 1, 2, ... and
   map column/zero-based row.
5. Rolls initial HP through the persistent native `run.niche` stream,
   commits native `run.monster_ai` intents and carries native cursors
   through real combat, snapshots and enemy-turn transitions.
6. Preserves encounter-local starter rotations sampled before combat
   for Corpse Slugs Normal and Two-Tailed Rats Normal.

## Source-dependent deviations from the legacy prototype

| Encounter | Native generation |
|---|---|
| Flyconid Normal | One encounter-local `NextItem` selects a medium slime; slime first, Flyconid second |
| Ruby Raiders Normal | Three `NextItem` draws without replacement, from dictionary insertion order Axe, Assassin, Brute, Crossbow, Tracker |
| Slimes Normal | One `NextBool` determines the order of two small slimes, following Twig M and Leaf M |
| Slithering Strangler Normal | First draw selects Jaxfruit, a medium slime, or two small slimes (with replacement). The Strangler is **last**; possible 1, 2, or 3 draws total |
| Corpse Slugs Normal | One encounter-local `NextInt(3)` rotates starters for three slugs; no second prototype opener draw |
| Two-Tailed Rats Normal | One encounter-local `NextInt(3)` rotates Scratch, Disease Bite, Screech, in slots `third`, `fourth`, `fifth` |
| Nibbits Normal | Native slots `front`, `back` preserved (unlike old unnamed prototype slots) |
| Overgrowth Crawlers | Native order is Shrinker Beetle then Fuzzy Wurm Crawler, reverse of prototype |
| Fogmog Normal | Native slot `fogmog` |
| Inklets Normal | All three native slot arguments are null (the central Inklet's special flag is independent of slot names) |
| Living Fog Normal | Native slot `livingFog` and formation position 5 |

The other 16 normal formations have **zero encounter-local RNG
draws**, and their source-order fixed enemy lists and slots are
transcribed directly. Native `Rng.NextBool` advances once via
`MegaRandom.Next(2) == 0`; even the singleton draws of Slimes Weak
continue to advance once.

## Fidelity limitations

This is an **initial encounter formation / HP / intent RNG** milestone,
not full normal-combat fidelity. Monster instance flags (such as
`MiddleInklet`), per-enemy `AfterAddedToRoom` effects, true native
monster-move graphs, summon behavior, card/potion shuffle and targeting
streams, encounter/reward bag logic, and source-exact map generation
need further migration and oracle checks. The opt-in engine now
**rejects any first-turn or later change to the initial enemy formation**
(summon, removal, transformation) if creature-local contexts cannot be
matched to the source-created monsters: it throws
`NotSupportedException` before returning a potentially unsnapshotable
combat state, rather than silently using prototype spawn RNG or
discarding invalid native contexts. Such fights can still enter
combat, but cannot continue past the unsupported lifecycle boundary.
Exact parity cannot be claimed without a real-game trace.

Unsupported elite, boss and event encounters remain strictly gated in
the experimental combat path. The normal encounter catalog does not
automatically make these fights native-fidelity.
