## Reflections

- **Touch a mirror:** choose up to two distinct cards upgraded at choice start;
  downgrade each one level. Recompute upgradability after those downgrades;
  choose up to four distinct eligible cards and upgrade each once.
  The selected identities are sampled without replacement using the
  deterministic prototype `event` RNG.
- **Shatter:** snapshot only the original deck; add one persistent clone for
  each original with a fresh instance ID, retained upgrade level,
  enchantment and cloned persistent state. After all clones, add exactly
  one Bad Luck. Existing card-added relic hooks run for new copies and curse.
- **Bad Luck:** Eternal, unplayable, unupgradable Curse; while present
  in the player's hand at turn end, lose 13 HP ignoring block. Existing
  typed end-turn-hand damage is reused.

## Round Tea Party

- Eligibility: at least 12 current HP at the initial choice.
- **Enjoy tea:** obtain event-only Royal Poison then heal to max HP.
- **Pick a fight:** moves to one follow-up option with no immediate HP loss.
  **Continue fight:** first lose 11 unblockable HP, then obtain one
  relic from the front of the current persistent rarity-bag. Lethal
  damage cancels the reward.
- **Royal Poison:** the owner's first player turn of combat suffers 4
  unblockable, unpowered HP damage per owned relic; later turns do
  not trigger. The initial turn begins directly during StartCombat in
  this emulator, so the callback executes at the end of combat setup.

Both events are reachable through the experimental Glory event selection and
explicit `PrototypeNativeLaterActFixture.CreateGloryEvent` fixtures. Round Tea
Party's 12-HP eligibility is applied before the experimental event draw. The
default configured route remains gated from later acts.

## Known parity boundaries

- Exact event `Rng`/native stable sampling, relic bag ownership,
  and native live traces are not yet validated. Event sampling and relic
  rarity use the existing deterministic prototype RNG/queues.
- Deck clones preserve the typed CardInstance state. Native CloneCard
  can carry further card-model payloads not yet represented in this
  emulator; extra modifications remain unsupported.
- Round Tea Party's follow-up is modeled by a typed page, but the
  source's `ThatWontSaveToChoiceHistory` UI distinction is not
  independently represented in the run-history schema.
- Event/relic/card statuses remain **partial** until RNG, full acquisition
  lifecycle and native trace parity are independently validated.
