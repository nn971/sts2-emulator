# v0.111.0 mechanics gap — pass 035

This pass promotes **Flyconid** and closes two more Overgrowth normal encounter formations.

## Flyconid model

Pinned v0.111.0 values:

- HP 47–49 at A0–A7;
- HP 51–53 at A8+;
- Vulnerable Spores: apply 2 Vulnerable;
- Frail Spores: deal 8 damage and apply 2 Frail;
- Frail Spores deals 9 at A9+;
- Smash: deal 11 damage;
- Smash deals 12 at A9+.

The source-shaped AI uses two random states.

### Initial state

The first turn cannot be Vulnerable Spores.

- Frail Spores: weight 2;
- Smash: weight 1.

This gives the native 2/3 versus 1/3 opener split.

### Main random state

After the opener, every move returns to one weighted random state:

- Vulnerable Spores: weight 3;
- Frail Spores: weight 2;
- Smash: weight 1.

Every branch uses `CannotRepeat`, so the previous move is removed from the legal weighted set before
selection.

Exact native RNG codec and call order remain outside the present parity claim.

## Existing debuff primitives

Flyconid requires no new player-status machinery.

Its spores reuse the already source-backed timed player powers:

- Vulnerable;
- Frail.

This is useful because Flyconid tests the same player-debuff path from a weighted random enemy AI
rather than from a fixed move sequence.

## Shroom and Slime

`FLYCONID_NORMAL` is now represented as:

- position 0: one random medium slime, either Leaf Slime (M) or Twig Slime (M);
- position 1: Flyconid.

The random medium slot uses the existing independent encounter-selection group abstraction.

Both medium choices are covered by deterministic-seed regressions.

## Overgrowth Flora

`SNAPPING_JAXFRUIT_NORMAL` is now represented as:

- position 0: Snapping Jaxfruit;
- position 1: Flyconid.

Snapping Jaxfruit was already implemented, so Flyconid was the only remaining model blocker for this
encounter.

## Regressions

Focused tests verify:

- A0/A8 HP ranges;
- A9 attack scaling;
- the first move is Frail Spores or Smash, never Vulnerable Spores;
- both opening choices are reachable;
- every main-loop move obeys the no-immediate-repeat constraint;
- Vulnerable Spores and Frail Spores apply the existing timed player debuffs;
- both random medium slime choices are reachable in Shroom and Slime;
- exact source-backed formation positions for Shroom and Slime and Overgrowth Flora.
