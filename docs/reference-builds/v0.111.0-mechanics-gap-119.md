# v0.111.0 mechanics gap 119 — Book of Five Rings

Book of Five Rings heals 20 HP each time the fifth, tenth, fifteenth, and
subsequent card is added to the deck. Its saved `CardsAdded` counter persists
between card grants, and healing stops at max HP.

The executable fixture checks the first and second thresholds, saved counter
values before and after each threshold, max-HP capping, and a melted copy.
The source also filters this relic out at or after the Act 3 treasure chest;
that late-run relic-eligibility filter remains open in the prototype pool.
