# Glory Hungry for Mushrooms event audit

Target: single-player STS2 v0.111.0 / source commit
`706ef1c9fa2219220065849fd5265328607ece20`.

The pinned [`HungryForMushrooms.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Events/HungryForMushrooms.cs)
offers Big Mushroom and Fragrant Mushroom as relic options. Big Mushroom's
`AfterObtained` gains 20 Max HP and the same amount of current HP; it reduces
the opening hand by two cards on the first combat turn. Fragrant Mushroom's
`AfterObtained` deals 15 unblockable, unpowered damage, then upgrades up to two
distinct eligible cards. Fatal damage prevents the upgrade pass. Both choices
finish the event and preserve the result page until continuation.

The complete active source branch inventory has seven paths:

| Source path | Behavior | Verification |
| --- | --- | --- |
| `page/INITIAL` | Present Big Mushroom and Fragrant Mushroom. | `CatalogueIsGatedAndContainsBothEventRelics` checks the pinned options and event-only relic definitions. |
| `initial/BIG_MUSHROOM` | Select Big Mushroom. | `BigMushroomGainsTwentyHpAndMaxHpAndPreservesFork` checks acquisition effects. |
| `page/INITIAL/BIG_MUSHROOM` | Resolve Big Mushroom and show its result. | Same test checks the terminal choice, state invariants, and snapshot restore. |
| `page/BIG_MUSHROOM` | Show the result and return to map choice. | Same test explicitly continues. |
| `initial/FRAGRANT_MUSHROOM` | Select Fragrant Mushroom. | `FragrantMushroomDamagesThenUpgradesTwoDifferentCards` checks ordered damage and two distinct upgrades. |
| `page/INITIAL/FRAGRANT_MUSHROOM` | Resolve relic acquisition, damage, and upgrades. | Same test checks the terminal choice, invariants, and snapshot restore; `FragrantNeverUpgradesWhenPickupDamageIsFatal` covers fatal damage before upgrades. |
| `page/FRAGRANT_MUSHROOM` | Show the finished result and return to map choice. | Same test explicitly continues. |

The `page/MEDLEY` key remains in English localization, but the pinned event
class has no Medley option or transition. The pinned
[2025-12-18 patch notes](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/localization/eng/patch_notes/2025_12_18.md)
explicitly deprecate that option. It is therefore excluded from the active
branch inventory rather than treated as implemented behavior.

`PrototypeNativeEventCompletionPages` retains the two active result pages.
Big Mushroom and Fragrant Mushroom acquisition hooks are covered through combat
and relic tests. Fragrant Mushroom uses the prototype event stream for its
candidate shuffle; native niche-stream cursor parity remains open. This audit
does not claim live-game certification.
