# v0.111.0 mechanics gap 090 — Candelabra

Candelabra is a shared Uncommon relic integrated into the supported relic
pool. At the start of the owner's second turn in combat, it grants two
Energy. Other turns and melted copies have no effect.

Executable coverage dispatches the owner-turn callback at turns one and two,
then checks the melted case. It verifies that Energy stays unchanged on turn
one and rises by two on turn two. Native combat callback timing remains
unverified against a live reference build.
