Pantograph is an Uncommon shared relic. Before each Boss combat, it heals 25
HP, capped at Max HP. The emulator applies the heal during combat setup when
the entered room is a Boss, across Overgrowth, Underdocks, Hive and Glory.
Relic acquisition queue and RNG parity remain unverified.
