# v0.111.0 mechanics gap 103 — Stone Cracker

Stone Cracker is an Uncommon shared relic. At combat start it upgrades up to
two random upgradeable cards in the draw pile for that combat. Statuses,
curses, and cards at their maximum upgrade level are skipped; the persistent
deck is unchanged, and melted copies do not trigger.
