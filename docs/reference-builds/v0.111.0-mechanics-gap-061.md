# v0.111.0 mechanics gap 061 — Tuning Fork

Pinned `TuningFork.cs` is an Uncommon relic. It counts its owner's Skill plays
across combats; every tenth Skill play grants 7 unpowered Block during that
combat. The emulator uses a per-instance persistent trigger counter, so the
threshold continues across combat entry and state snapshots. Tuning Fork is
included in the Uncommon relic pool, and coverage checks the counter property,
Skill-only trigger, threshold, Block amount, and pool rarity.
