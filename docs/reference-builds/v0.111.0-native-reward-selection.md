# v0.111.0 native Overgrowth reward selection

The emulator's native Act 1 Overgrowth combat reward phase exposes
card, potion, relic, and gold reward actions **independently**.
RewardState.IndependentSelection is true for these encounters and is
serialized with the remaining reward-progress flags. Older prototype
rooms and custom event rewards retain the ordered reward interaction
with IndependentSelection=false.

## Action semantics

* `take_reward_card` or `skip_reward_card` resolves the currently
  available card group; additional card groups advance one at a time.
* `take_reward_potion`, `replace_reward_potion`, or
  `skip_reward_potion` can be chosen before, during, or after card
  selection; replacement is offered for full potion slots.
* `take_reward_relic` resolves the first relic group, followed by
  extra relic offers if present. Other reward types can be collected
  before or between relic groups.
* `take_reward_gold` transfers the offered amount exactly once.
* `leave_reward` always abandons all remaining optional rewards,
  including unapplied card choices and unclaimed gold.

A pending relic-triggered deck-removal/transform/upgrade selection,
or an unresolved mandatory card bundle, suspends the independent
options until completed. Invalid or repeated pickups are rejected.
The public AI observation exposes IndependentSelection and all
individually pending reward types. Reward contents are generated at
combat completion, so selecting their buttons in another order does
not reroll already offered rewards.

## Remaining fidelity differences

Within a *single type*, multiple card and extra relic groups are
still resolved in order rather than represented as multiple
individually addressable reward buttons. Some relics in native STS2
can also mutate already generated reward options when obtained during
the reward screen; such dynamic modification is a separate task.
Native UI animations, early-skip hints, and exact RNG replay have not
been implemented. No cross-character or multiplayer rewards are
introduced.
