# v0.111.0 Glory A10 double-boss route

Pinned source: `Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`.

The source `ActModel` identifies the second boss as the Double Boss rule at
Ascension 10+. `RunManager.GenerateRooms` selects it only for the final act,
after every act has generated its rooms, from the final act's boss pool with the
first boss excluded. `StandardActMap` places a second boss node one row after
the first boss and connects the two nodes in sequence.

The experimental route now stores an optional `SecondBossEncounterId` in its
Glory encounter history. It creates the extra terminal map node at A10+, enters
the saved second encounter on that floor, and keeps the first boss reward from
ending the act. The second boss reward completes Glory and the run. Hive and
Glory below A10 keep one boss; Hive never receives a second boss from this rule.

Verification covers the A9/A10 boundary, distinct boss identities, A10 map
validation, the first-boss continuation, both boss combats, and synthetic final
victory through the public route engine. This remains an experimental
implementation: boss selection currently consumes the prototype combat stream
during run-start history preparation. Native `run.up_front` ownership, exact
`NextItem` ordering after all acts, boss-reward ordering, and real-game traces
remain unverified.
