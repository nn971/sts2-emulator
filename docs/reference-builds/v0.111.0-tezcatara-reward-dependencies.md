Tezcatara generates one offer from each of three pools. The first contains
Very Hot Cocoa and Yummy Cookie, adding Nutritious Soup when the deck contains
a basic Strike. The second contains Biiig Hug, Storybook and Toasty Mittens.
The third contains Golden Compass, Pumpkin Candle, Toy Box and Seal of Gold.
Three source RNG calls select the offers. A truncated executable subset cannot
stand in for those distributions.

## S0 stochastic site contract: `event.tezcatara.relic_offer.index_draw`

This site resolves three ordered offer pools at an unvisited Act 2, floor 0
Hive Ancient boundary, using `context.event.TEZCATARA.player_0` and request
ordinals 0–2. The first pool contains Very Hot Cocoa and Yummy Cookie, plus
Nutritious Soup when the deck has a Basic rarity card tagged `Strike`; the
presence check includes already-enchanted Strikes. The second pool contains
Biiig Hug, Storybook and Toasty Mittens. The third contains Golden Compass,
Pumpkin Candle, Toy Box and Seal of Gold. The ordered candidate lists are
private generation constraints.

The event stores the selected `OfferedChoiceIds` and completed RNG context;
the player observation exposes the resulting offers and visible choice
values. The opt-in `chance_law_query` supports this site through
`ChanceLawEngineV111.QueryAncientOffer`, which shares the `TezcataraPools`
eligibility builder and returns stable choice identities with support and
conditioning fingerprints. This is query-only coverage: no atomic
ReferenceNature session consumes the offer choices, and EventState does not
persist a separate support fingerprint or pre-outcome candidate list.
Probability provenance remains `UNVERIFIED`; native cursor and UpFront
assignment fidelity remain open. Invalid boundaries and unsupported sites
fail closed. This contract does not provide a privileged-inspector projection.

These branches are available through the configured Hive Ancient assignment.
`BeginTezcataraOpening` samples the complete three-offer pools at an unvisited
Hive Ancient boundary. Pool order and the conditional Soup entry match the
source; Soup checks Basic Strike presence, including already-enchanted Strikes.
Three native NextItem calls use the existing `ForEvent(seed, "TEZCATARA")`
context and codec. Its post-generation stream is persisted on EventState,
deep-forked, and validated by recomputing the exact three offers and post-draw
cursor when loading snapshots. Legal actions preserve the displayed pool
order; a different relic from the same valid pool is rejected. The selected
relic uses the shared acquisition continuation, then its Ancient `DONE` page
is retained until dismissed. This source audit is not a live native-game cursor
certification. Native UpFront assignment call order, account unlock filtering
and RNG cursor parity remain for the fidelity pass.
