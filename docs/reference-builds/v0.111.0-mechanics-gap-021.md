# v0.111.0 mechanics gap — pass 021

This pass adds typed Ascension state and reusable Ascension scaling, with Knight Gang as the
source-backed acceptance case.

## Typed run state

`RunState` now carries `Ascension`.

`PrototypeGameFactory.Create(seed, ascension)` validates that the level is non-negative and stores
it in the canonical deterministic state. Forking preserves the value automatically.

Ascension therefore participates in canonical hashes rather than existing as an external simulator
configuration that could silently change transition semantics.

## Reusable scaling data

The model now has `PrototypeAscensionDelta(MinAscension, Delta)`.

Enemy definitions can attach cumulative deltas to:

- maximum HP;
- individual enemy-effect amounts.

An enemy/effect evaluates all deltas whose minimum Ascension has been reached.

This supports multiple future breakpoints without adding fields such as `A8Hp`, `A9Damage`, or
enemy-specific branches.

The existing prototype `AmountPerAct` field remains independent and composes with Ascension deltas.

## Combat integration

Combat creation uses the typed run Ascension when calculating enemy HP.

Enemy action resolution receives the same typed value and evaluates each effect through its
Ascension-aware amount function.

The random move policy itself does not change with Ascension; only the source-backed values attached
to its moves change.

## Knight Gang scaling

The production Knight Gang definitions now include:

### Ascension 8+

- Flail Knight HP: 101 -> 108;
- Spectral Knight HP: 93 -> 97;
- Magi Knight HP: 82 -> 89;
- Magi Power Shield Block: 5 -> 9;
- Magi Prep Block: 5 -> 9.

### Ascension 9+

- Flail: 9x2 -> 10x2;
- Flail Ram: 15 -> 17;
- Spectral Soul Slash: 15 -> 17;
- Spectral Soul Flame: 3x3 -> 4x3;
- Magi Power Shield damage: 6 -> 7;
- Magi Ram: 10 -> 11;
- Magi Magic Bomb: 35 -> 40.

War Chant still grants 3 Strength, while Hex and Dampen keep their existing non-numeric semantics.

## A9 combined regression

A fixed-seed A9 Knight Gang regression executes the same first five turns as the A0 encounter test.

It verifies the scaled combined incoming HP sequence:

- after turn 1: 476/500;
- after turn 2: 439/500;
- after turn 3: 396/500;
- after turn 4: 379/500;
- after turn 5: 307/500.

It also verifies 9 Block on Magi's Power Shield/Prep turns.

This proves the typed run Ascension reaches real enemy transition execution rather than merely being
stored in static content.

## External run interfaces

Ascension is exposed through all current prototype run entry points:

- `prototype-run [seed] [ascension]`;
- `prototype-sweep [n] [ascension]`;
- `PrototypeAiEnvironment.Reset(seed, ascension)`;
- AI JSONL `reset` with optional integer field `ascension`.

The default remains Ascension 0, so existing callers are backward compatible.

AI forks preserve Ascension and therefore preserve canonical hashes/search semantics.
