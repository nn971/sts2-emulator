# v0.111.0 mechanics gap 085 — Toy Box

Toy Box is an Act 2 Tezcatara reward. Acquiring it offers five distinct relics
reserved from the current front bag and marks each selected relic as wax. At
every third combat exit it melts the first unmelted wax relic in inventory
order, stopping after fifteen combats.

Executable coverage samples Tezcatara until Toy Box is offered, acquires it
through the event action, verifies five distinct reserved offers, and selects
all five as wax relics. It then checks combat counts one through fifteen,
ordered melting, duplicate combat-exit idempotence, the fifteen-combat cap,
and that a melted Toy Box does not advance its count. Native relic-bag
eligibility and RNG parity remain unverified.
