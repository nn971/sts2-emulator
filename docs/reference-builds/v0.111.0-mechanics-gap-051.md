# v0.111.0 mechanics gap 051 — Tungsten Rod

Pinned `TungstenRod.cs` is a Rare shared relic. Its
`ModifyHpLostAfterOsty` hook applies to its owner and reduces every positive HP
loss by one, clamped at zero.

The emulator registers the canonical relic in the ordinary Rare pool and
applies the reduction in the shared combat HP-loss path before Buffer. It also
covers run effects, event choices, delayed event losses, and the configured
Overgrowth, Underdocks, Hive, and Glory event handlers that express HP loss
directly. The existing player damage event receives the reduced amount.
