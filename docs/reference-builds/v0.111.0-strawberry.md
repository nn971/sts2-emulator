# v0.111.0 Shared Relic: Strawberry

Target: v0.111.0 / 41cef1ea, audited source
`Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`.

Source: [`Strawberry.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Relics/Strawberry.cs).

Strawberry is a Common shared relic. On acquisition it grants 7 Max HP. The
emulator integrates that acquisition through its `GainMaxHp` run effect,
which increases both maximum and current HP, and registers Strawberry in the
Silent shared relic pool and common rarity queue.

The model covers the native pickup effect and rarity. Relic queue generation
and RNG parity remain unverified.
