# Hive Spirit Grafter event audit

Target: single-player STS2 v0.111.0 / source commit
`706ef1c9fa2219220065849fd5265328607ece20`.

The pinned [`SpiritGrafter.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Events/SpiritGrafter.cs)
has source SHA-256
`3be1eb82235e62924fb5437399610e2d73e5550da31d3c373627cf9ff5e05098`. Let It
In heals 25 HP and adds Metamorphosis, then finishes the event. Rejection lets
the player upgrade a deck card when possible, deals 10 unblockable damage, and
finishes the event. The result page stays open until the player continues.

The complete source branch inventory has seven paths:

| Source path | Behavior | Verification |
| --- | --- | --- |
| `page/INITIAL` | Present Let It In and Rejection. | `SourceEligibilityAndGatedActTwoDefinitions` checks the pinned choices and the branch tests select both through legal actions. |
| `initial/LET_IT_IN` | Select Let It In. | `GrafterLetItInHealsAndAddsOneMetamorphosis` checks the healing, added card, and next instance ID. |
| `page/INITIAL/LET_IT_IN` | Resolve the initial Let It In option. | Same test verifies the event remains open on its result page. |
| `page/LET_IT_IN` | Show the finished Let It In result, then return to the map. | Same test checks snapshot round-trip and explicit continuation. |
| `initial/REJECTION` | Select Rejection and offer a card upgrade when possible. | `GrafterRejectionUpgradesBeforeUnblockableHpLoss` selects a legal upgrade action and checks that HP loss follows it. |
| `page/INITIAL/REJECTION` | Resolve the initial Rejection option. | Same test verifies the pending card choice is snapshot-safe; `GrafterRejectionStillFinishesWhenNoCardCanBeUpgraded` covers the empty-choice path. |
| `page/REJECTION` | Show the finished Rejection result, then return to the map. | Both Rejection tests check the result page and explicit continuation; the upgrade test also validates invariants and snapshot restore. |

`PrototypeNativeHiveEvents` identifies Spirit Grafter as an event with a
terminal choice page. `PrototypeEventContinuations` preserves that page after
effects resolve, and `PrototypeRooms` exposes `continue_event` and records the
map room only when continuation is taken. Rejection uses the regular legal deck
upgrade choice, followed by the event's 10 HP loss.

This closes the source branch inventory for Spirit Grafter only. The native
event RNG cursor and live-game parity remain outside this branch audit.
