# v0.111.0 mechanics gap 049 — canonical Trash Heap relic IDs

The pinned `TrashHeap.Relics` list obtains `DarkstonePeriapt`, `DreamCatcher`,
`HandDrill`, `MawBank`, and `TheBoot` through their canonical model types. The
emulator now uses the canonical `proto.relic.*` IDs for all five rewards; it
previously assigned event-local IDs to four of them.

Hand Drill's block-break Vulnerable, Maw Bank's room-entry gold, and The Boot's
powered-attack HP-loss floor now share their normal relic identity wherever
acquired. The four Event relics remain in Trash Heap's reward list and outside
the ordinary relic pool.
