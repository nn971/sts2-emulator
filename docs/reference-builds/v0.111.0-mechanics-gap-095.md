# v0.111.0 mechanics gap 095 — Cloak Clasp

Cloak Clasp is a shared Rare relic integrated into the supported relic pool.
At the end of the owner's turn, it grants one unpowered Block per card still
in hand. A melted copy has no effect.

Executable coverage dispatches the turn-end trigger with three hand cards,
with an empty hand, and with a melted relic. It checks that the first case
adds three Block and the other cases add none. Native callback timing remains
unverified against a live reference build.
