# Underdocks: first native-shaped single-player slice (v0.111.0)

This is **an opt-in partial Act 1 region**, not a claim that
Underdocks can be completed in the emulator yet.

Source pin: `Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`:
`src/Core/Models/Acts/Underdocks.cs`,
`src/Core/Models/Encounters/{SeapunkWeak,SludgeSpinnerWeak,ToadpolesWeak,CorpseSlugsWeak}.cs`
and the corresponding monster models.

## Activation

`PrototypeNativeUnderdocksRunFactory.Create(seed, ascension)` produces the
native-shaped Silent Act 1 opening with the shared Neow event, starter deck,
Ascension adjustments, a 15-room/16-floor map and the distinct
`native-underdocks-map-structure-v0.111.0-v1` map profile.

The existing Overgrowth factory and ordinary `PrototypeGameFactory` reset
remain unchanged. Underdocks is **not** the default run mode.

## Source inventory (20 encounters)

| Room | Number | Native inventory | Implemented |
| --- | ---: | --- | --- |
| Weak ordinary | 4 | Corpse Slugs, Seapunk, Sludge Spinner, Toadpoles | **3 / 4** (all except Corpse Slugs) |
| Normal ordinary | 10 | Corpse Slugs, Cultists, Fossil Stalker, Gremlin Merc, Haunted Ship, Living Fog, Punch Construct, Seapunk, Sewer Clam, Two-Tailed Rats | 0 / 10 |
| Elite | 3 | Phantasmal Gardeners, Skulking Colony, Terror Eel | 0 / 3 |
| Boss | 3 | Waterfall Giant, Soul Fysh, Lagavulin Matriarch | 0 / 3 |

The initial **three** ordinary combats draw without replacement from
the explicitly supported **three** weak encounters. This is deliberately a
restricted distribution: in the real game, Corpse Slugs is a fourth weak
candidate. The skipped candidate has not been silently replaced.

Seapunk and Toadpole already have native-shaped move models in the shared
catalog; this slice improves Seapunk's A8 block and A9 Strength values,
adds Sludge Spinner's 37–39 HP (A8: 41–42), forced Oil Spray,
no-repeat weighted continuation (Oil Spray, Slam, Rage), Weak and Strength,
and registers the three weak formations, including front/back Toadpoles.

## Explicitly unsupported / next steps

- Normal, elite and boss **combat** entry fails with `NotSupportedException`,
  rather than selecting Overgrowth enemies or the legacy pseudo-Act-1 pool.
- The selected boss is stored as **native inventory metadata** but is not
  spawnable until its model and formation are implemented.
- Underdocks-specific events and its exact event-selection pool are not yet
  translated. At ordinary event nodes, the existing prototype events remain
  available; they are **not native Underdocks fidelity**.
- Rewards, merchants and act transitions still follow the applicable
  prototype/native-shaped shared rules, which are not a claim of full
  native Underdocks semantics.
- The map shares the same geometry approximation as Overgrowth because both
  pinned Act 1 source classes specify `BaseNumberOfRooms=15`,
  `NumberOfWeakEncounters=3`, and the same map-point distributions.
  Exact native RNG seed parity remains a separate track.

**Recommended next work:** add Corpse Slugs weak, including its two distinct
opening moves and Ravenous lifecycle, then migrate the 10 normal encounters,
three elites and bosses, followed by the 10 events. Keep each new monster's
move logic reusable and source-backed, but do not block the breadth track
on exact RNG sequence matching.

## Regression surface

`PrototypeUnderdocksOpeningTests` verifies native inventory counts,
opt-in initialization, map profile/Neow/starter, unique weak bag depletion,
implemented formations, unsupported-combat gating, Sludge Spinner model,
canonical fork hashing and unchanged default Overgrowth resets.

These are lightweight functionality tests, **not** live oracle differentials.
