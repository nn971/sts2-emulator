# Sunken Statue event audit

Target: single-player STS2 v0.111.0 / source commit
`706ef1c9fa2219220065849fd5265328607ece20`. This event is shared by
Overgrowth and Underdocks.

The pinned [`SunkenStatue.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Events/SunkenStatue.cs)
has source SHA-256
`5c60d58620b3ab002ab676c72c30b621ff4281d1d2f6e49e4cdc98d484781053`. On
entry, the event stores 111 plus an inclusive `[-10, 10]` gold roll. Grab Sword
obtains Sword of Stone. Dive grants the stored gold and deals 7 unblockable,
unpowered damage. Each successful choice finishes the event and leaves a result
page before map continuation.

The complete source branch inventory has seven paths:

| Source path | Behavior | Verification |
| --- | --- | --- |
| `page/INITIAL` | Present Grab Sword and Dive Into Water. | `StatueGoldRollIsPersistedAndSwordIsAnAlternativeReward` checks the persisted gold and both alternatives. |
| `initial/GRAB_SWORD` | Choose Sword of Stone. | Same test verifies the relic is granted without changing HP or gold. |
| `page/INITIAL/GRAB_SWORD` | Resolve the initial relic choice. | Same test verifies a completed result page. |
| `page/GRAB_SWORD` | Show the sword result and return to the map. | Same test explicitly continues to map choice. |
| `initial/DIVE_INTO_WATER` | Choose Dive Into Water. | Same test verifies the stored gold and 7 HP loss. |
| `page/INITIAL/DIVE_INTO_WATER` | Resolve the initial dive choice. | Same test verifies the finished result page after damage and reward. |
| `page/DIVE_INTO_WATER` | Show the dive result and return to the map. | Same test explicitly continues; fork equality confirms the source state is unchanged by resolving either alternative. |

The event-entry roll remains persisted in the event state and is not rerolled
for either choice. Finished-page metadata is shared with the other audited
native events. This branch audit does not claim native RNG cursor parity or
live-game certification.
