# Run-start Hive/Glory encounter histories

Target: v0.111.0 / 41cef1ea; source pin
`Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`.
Extends the existing pre-generated encounter queue implementation rather than
introducing a second regional selector.

The experimental Silent three-act route now prepares both later-act encounter
histories during run initialization, before selectable map traversal. Future
histories are canonical hidden state in `PreparedLaterActEncounterBags`.
Entering an act transfers an independent copy into the active queue and removes
that act from the future list. No encounter identity draw occurs at act entry.
Earlier combat/event choices therefore cannot change future prepared histories.

Validation requires one untouched queue for each future act, in route order,
with the existing native-shaped weak/normal/elite lengths and valid regional
identities. Snapshots and forks preserve independent copies. Old experimental
snapshots without the new future histories must be regenerated; they fail
validation instead of drawing replacements from a later RNG cursor. Default
v111 and legacy prototype paths do not create this field.

This closes the act-entry timing gap but does not establish native upfront
generation parity. Act 1 preparation still uses its existing implementation;
later histories retain the prototype combat stream, eligible-subset selection,
and existing pool ordering. Native shared-Ancient assignment, event shuffles,
`run.up_front` ownership and rejection-draw ordering remain to be implemented
through the desired random-decision architecture. Do not switch streams alone
and claim seed parity.

Verification: 1,612 C# tests pass; reviewed coverage baseline and Python
snapshot/batch/replay compatibility checks pass. A 256-run legal-action A0
sweep (128 per starting region) terminates without blockers, all in defeat;
12 reach Hive and none reach Glory. All 12 saved natural Hive checkpoints
resume independently to the identical terminal hashes and outcomes. These are implementation integrity checks,
not native parity or full regional branch coverage.
