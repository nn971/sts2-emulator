# v0.111.0 mechanics gap 126 — Vexing Puzzlebox

At the start of its owner's first turn in combat, Vexing Puzzlebox adds one
random card from that character's card pool to hand and makes it free for the
turn.

The executable coverage fixture checks its Rare relic pool entry, the card
creation and temporary free cost, and no trigger on later turns, for a melted
copy, or on an inactive player side. Card generation currently uses the
emulator's supported Silent pool.
