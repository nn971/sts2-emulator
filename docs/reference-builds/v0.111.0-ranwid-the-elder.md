# v0.111.0 Event: Ranwid the Elder

Target: v0.111.0 / 41cef1ea, audited source
`Flaaax/STS2-source@706ef1c9fa2219220065849fd5265328607ece20`.

Source: [`RanwidTheElder.cs`](https://github.com/Flaaax/STS2-source/blob/706ef1c9fa2219220065849fd5265328607ece20/src/Core/Models/Events/RanwidTheElder.cs).

The source event is available after the first act when the player has at least
100 gold, a potion, and a tradable relic. Its three outcomes trade the selected
potion for one relic, spend 100 gold for one relic, or trade the selected
relic for two relics. The event saves the selected potion and relic before
presenting the choices. It appears in the configured Hive and Glory pools.

The emulator snapshots those two offers in event state, removes the selected
asset, grants the source-shaped number of relics, applies acquisition run hooks,
and preserves the result page. Relic draw order and native RNG call parity
remain for the later fidelity pass.
