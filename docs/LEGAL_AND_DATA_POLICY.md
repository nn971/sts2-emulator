# Legal and data policy

This project is intended as independent research infrastructure for interoperability, deterministic simulation, testing, and downstream research use.

## Repository policy

Do not commit:

- proprietary game assets;
- copied/decompiled game source text;
- redistributed game assemblies;
- copyrighted presentation content unnecessary for the mechanical interface.

Prefer:

- independently written behavioral implementations;
- documented observations of runtime behavior;
- hashes, IDs, schemas, and small semantic fixtures;
- user-local extraction/instrumentation tools where legally appropriate;
- version/provenance metadata instead of bundled proprietary source.

## Reference data

If static metadata is extracted from a locally installed game, keep the extraction process and provenance explicit. Decide separately whether resulting data may be redistributed; default to keeping uncertain/proprietary datasets local.

## Traces

Canonical traces should minimize presentation/copyright content. Prefer mechanical IDs and state over art, localization text, audio, or other assets.

## Trademarks

Slay the Spire 2 and related marks belong to their respective owners. This repository should make clear that it is an independent project.
