# Native Tezcatara Toy Box ReferenceNature continuation

**Snapshot:** 2026-10-19. **Status:** implemented as an atomic configured Native Tezcatara choice session; relic identity pool fidelity and Native cursor parity remain open.

## Boundary

`ReferenceNatureNativeEventRelicSessionV111` starts from a currently legal
Tezcatara event choice whose effects grant Toy Box on a configured Native
route. It replays that ordinary `event_choice` action and captures the five
relic draws used to create Toy Box's Wax relic reward. The action, five rarity
rolls, five identity selections, completed Reward, and ReferenceNature cursor
form one saved boundary.

Event selection happens before this boundary and keeps its current provider.
The session rejects a different event, choice, route, or stochastic site
outside the relic rarity and relic model sites. Until all ten requests resolve,
its published run remains at the projected origin. On completion it commits
the Reward and Nature cursor together.

## Law and replay

The session uses `QueryNativeRelicRarity` for each
`relic_grab_bag.rarity.unit_float` request. It maps the selected rarity back to
a representative source float within that threshold interval. The Native
threshold transform is `SOURCE_VERIFIED` for the declared `player.rewards`
request.

For each `treasure.relic_grab_bag.model.index_draw`, replay rebuilds the
canonical remaining relic bag from the origin and the prior selected
identities. It validates the requested rarity, fallback tier, sorted
candidate identities, owner hash, and support before querying the exact Native
bounded-index law. The sorted Nature set deliberately omits Native queue
order. The bounded transform is `SOURCE_VERIFIED`; candidate-pool completeness
and the conditional Native identity distribution over its hidden queue remain
`UNVERIFIED`.

Each `ResolveNext()` samples the next law and maps it to the typed Native
float or index provider value, then replays the action from its saved origin.
Save/restore recomputes the complete prefix. Forks keep independent snapshots.
JSONL and Python expose begin, status, resolve, fork, save, load, release, and
the committed playable run.

## Scope limits

The session covers only Native Tezcatara choices that grant Toy Box. It does
not cover legacy Toy Box offers, unrelated relic-acquisition triggers, or
other event rewards. The implementation does not claim source-pool
completeness, hidden queue identity probabilities, event-selection parity,
seeded Native result parity, or Native cursor parity. The Native reference mod
and Fidelity Inspector remain needed for those source-evidence tasks.
